> นักเรียนจะ **"จ้าง" ผู้ช่วย AI 1 คน** ให้ทำงานในอาชีพที่ตัวเองสนใจ แล้วทดลองใช้มันจนเข้าใจข้อจำกัด 5 เรื่องที่เรียนมา:
> **Token · Context Window · Hallucination · Memory · System Prompt & Role**
>
> ส่งงานเป็น **"การ์ดผู้ช่วย AI" 1 หน้า** + **หลักฐานการทดลอง 5 ภารกิจ**

## 1. ทำไมต้องทำการบ้านนี้

การใช้งาน AI ให้เก่งไม่ได้เกิดจากการอ่านอย่างเดียว แต่เกิดจากการ **ลองผิด ลองถูก แล้วสังเกตว่ามันผิดตรงไหน**

การบ้านชุดนี้จึงไม่ใช่ "ถาม AI แล้วส่งคำตอบ" แต่คือ **การทดลองทางวิทยาศาสตร์** ที่นักเรียนเป็นผู้สังเกต และ **งานสร้างสรรค์** ที่นักเรียนเป็นผู้ออกแบบ

> [!tip] เกณฑ์สำคัญที่สุด
> เราให้คะแนนที่ **กระบวนการคิดและหลักฐานจากการทดลอง** ไม่ใช่ความสวยของคำตอบ AI

---

## 2. ขั้นเตรียมการ (ก่อนเริ่ม ทำ 3 อย่าง)

1. **เลือกอาชีพ/ธุรกิจ** ที่จะให้ผู้ช่วย AI ทำงานด้วย — เลือกจาก
   * ร้านซ่อมคอมพิวเตอร์/มือถือ
   * ร้านกาแฟหรือร้านอาหาร
   * ทีมช่างไฟฟ้า/ช่างแอร์
   * ศูนย์ซ่อมของโรงเรียน
   * ร้านขายอะไหล่/อุปกรณ์ไอที
   * หรืออาชีพอื่นที่นักเรียนสนใจ (ขออนุมัติครูก่อน)
2. **เปิดบัญชีฟรี** ChatGPT หรือ Gemini (ใช้บัญชีของตัวเอง ไม่ใช้ของผู้อื่น)
3. **สร้างโฟลเดอร์เก็บหลักฐาน** ชื่อ `การบ้าน AI_<ชื่อนักเรียน>` ไว้เก็บภาพหน้าจอ

> [!danger] กฎความปลอดภัย (หักคะแนนหากฝ่าฝืน)
> * **ห้าม** พิมพ์ชื่อ-นามสกุลจริงของผู้อื่น, เบอร์โทร, ที่อยู่, เลขบัตรประชาชน หรือรหัสผ่าน
> * **ห้าม** ใส่ข้อมูลภายในองค์กรหรือข้อมูลลูกค้าจริง
> * ถ้าภาพหน้าจอมีชื่อเพื่อนหรือข้อมูลส่วนตัว ให้ **เบลอหรือครอปออก**
> * ใช้เฉพาะข้อมูลสมมติที่นักเรียนสร้างขึ้นเอง

## 3. ภารกิจที่ 1 — นักสืบ Token (15 คะแนน)

**เป้าหมาย:** เข้าใจว่า AI มองข้อความเป็น "ชิ้นส่วน" ไม่ใช่คำ และจับได้ว่า AI **เดา token ผิด**

### สิ่งที่ต้องทำ

**ตอน A — ไทย vs อังกฤษ**

1. เขียนคำถามเดียวกัน 2 ภาษา เช่น
   * ไทย: "อธิบายวิธีเปลี่ยนยางรถยนต์ให้ฟังหน่อย"
   * อังกฤษ: "Explain how to change a car tire."
2. ถาม AI ทั้งสองภาษา (แชทใหม่แยกกัน)
3. บันทึก: ความยาวคำตอบ (จำนวนบรรทัด), ความเร็วที่รู้สึกได้, ความครบถ้วน

| ภาษา | จำนวนบรรทัด | รู้สึกเร็ว/ช้า | ครบถ้วนแค่ไหน |
| :--- | :--: | :--- | :--- |
| ไทย | | | |
| อังกฤษ | | | |

**ตอน B — จับ AI โกหกเรื่อง token**

1. ถาม AI ว่า **"ประโยคนี้มีกี่ token: 'ระบบเครือข่าย VLAN 10 ใช้งานไม่ได้'"**
2. บันทึกคำตอบที่ AI บอก
3. ประมาณด้วยกฎที่เรียน:
   * ภาษาอังกฤษ ≈ 1 token ต่อ 4 ตัวอักษร
   * ภาษาไทย ≈ 1 token ต่อ 1–2 ตัวอักษร
4. เปรียบเทียบว่าตัวเลขของ AI **ใกล้หรือห่าง** จากที่คำนวณได้
5. สรุป 2–3 บรรทัด: เพราะอะไร AI จึงนับ token ไม่แม่น

> [!note] เฉลยแนวคิด (อ่านหลังทำเสร็จ)
> โมเดลไม่ได้ "เห็น" ตัวอักษรเหมือนเรา แต่มันเห็น token ที่ถูกตัดไว้แล้วในรูปตัวเลข
> การที่มันตอบตัวเลขออกมาได้ **ไม่ได้แปลว่ามันนับจริง** — มันแค่ทำนายตัวเลขที่ "ดูสมเหตุสมผล"
> นี่คือ **Hallucination** รูปแบบหนึ่งที่เกิดขึ้นแม้กับเรื่องที่ดูง่ายที่สุด

## 4. ภารกิจที่ 2 — สายลับความจำปลาทอง (15 คะแนน)

**เป้าหมาย:** สังเกตว่า Context Window จำกัด และ AI "ลืม" ได้

### สิ่งที่ต้องทำ

1. เปิดแชทใหม่ ตั้งรหัสลับของตัวเอง เช่น
   > "รหัสลับของฉันคือ **ปลาทองสีทอง 427** จำไว้ให้ดี"
2. คุยเรื่องอื่นต่อ **อย่างน้อย 15 ข้อความ** (ถามเรื่องเรียน ถามสูตรอาหาร ขอเล่าเรื่อง ฯลฯ)
3. ถามกลับว่า **"รหัสลับของฉันคืออะไร"** → บันทึกผล
4. เปิด **แชทใหม่** แล้วถามว่า **"รหัสลับของฉันคืออะไร"** → บันทึกผล
5. วาด **เส้นเวลา** ว่าความจำเริ่มจางตอนไหน (ข้อความที่เท่าไร)

| สถานการณ์ | AI จำได้หรือไม่ | ข้อสังเกต |
| :--- | :--- | :--- |
| แชทเดิม หลังคุย 15 ข้อความ | | |
| เปิดแชทใหม่ | | |

> [!tip] คำถามชวนคิด
> ถ้า AI จำรหัสลับไม่ได้ เพราะ "ลืม" หรือเพราะ "ไม่เคยเก็บ"?
> แล้วถ้าเปิด Memory ไว้ ผลจะต่างไหม? (ทดลองเพิ่มได้ เป็นโบนัส)

## 5. ภารกิจที่ 3 — นักประดิษฐ์ของปลอม (20 คะแนน)

**เป้าหมาย:** เห็น Hallucination ด้วยตาตัวเอง และฝึกแยก "ความมั่นใจ" ออกจาก "ความจริง"

### สิ่งที่ต้องทำ

1. **ประดิษฐ์อุปกรณ์ปลอม** 1 อย่าง ที่ไม่มีอยู่จริง (ห้ามใช้อุปกรณ์ที่มีขายจริง)
   * ตัวอย่าง: "หูฟัง AI รุ่น NeuroBeat X9", "เครื่องชาร์จพลังงานแสงจันทร์ LunarCharge"
   * ตั้งชื่อ + จุดเด่น 2 ข้อในใจ (ยังไม่ต้องบอก AI)
2. ถาม AI 3 คำถาม:
   * "สเปกของ [ชื่ออุปกรณ์] คืออะไร"
   * "ราคาเท่าไร ขายที่ไหน"
   * "รีวิวจากผู้ใช้เป็นอย่างไรบ้าง"
3. ให้คะแนนคำตอบแต่ละข้อ

| คำถาม | AI ตอบว่าอะไร | ระดับความมั่นใจ (1–5) | จริง/เท็จ | หลักฐานที่ใช้ตัดสิน |
| :--- | :--- | :--: | :--: | :--- |
| สเปก | | | | |
| ราคา | | | | |
| รีวิว | | | | |

4. เขียน **"สัญญาณอันตราย 3 ข้อ"** ที่ทำให้รู้ว่าคำตอบนี้ไม่น่าเชื่อถือ

> [!warning] กฎของภารกิจนี้
> **ห้ามแก้คำถามให้ AI รู้ว่าของปลอม** — เรากำลังทดสอบว่า AI กล้าแต่งหรือกล้าบอกว่าไม่รู้

## 6. ภารกิจที่ 4 — ออกแบบ System Prompt และบทบาท (25 คะแนน)

**เป้าหมาย:** ฝึกกำหนดบทบาทและกฎให้ AI ทำงานในแบบที่เราต้องการ

### สิ่งที่ต้องทำ

**ตอน A — เขียน System Prompt (6 องค์ประกอบ)**

เขียนในไฟล์ Word/โน้ต โดยมีครบ:

| องค์ประกอบ | ต้องระบุ |
| :--- | :--- |
| 1. บทบาท | ผู้ช่วยของเราคือใคร มีประสบการณ์แบบไหน |
| 2. ขอบเขต | ตอบเรื่องอะไรได้/ไม่ได้ |
| 3. ข้อมูลอ้างอิง | ใช้ข้อมูลจากไหน |
| 4. รูปแบบผลลัพธ์ | ตอบเป็นตาราง/ข้อ ๆ/ความยาวเท่าไร |
| 5. ข้อห้าม | ห้ามอะไร (ต้องมี "ถ้าไม่รู้ให้บอกไม่รู้") |
| 6. โทนภาษา | สุภาพ/กันเอง/กระชับ |

**ตอน B — ทดลองเปรียบเทียบ**

เลือกคำถามงานจริง 1 ข้อ แล้วถาม 2 แบบ:

| แบบ | คำถามที่ใช้ | ผลลัพธ์ที่ได้ |
| :--- | :--- | :--- |
| ไม่มีบทบาท | "ช่วยตอบเรื่อง..." | |
| มีบทบาท + system prompt | ใช้ prompt ที่เขียน | |

**ตอน C — วิเคราะห์**

เขียน 3–5 บรรทัด: บทบาทเปลี่ยนอะไรบ้าง? ยังมีจุดที่ AI ยังทำพลาดอยู่ไหม?

> [!tip] ตัวอย่าง System Prompt (ใช้เป็นแนว ไม่ต้องลอก)
> "คุณคือผู้ช่วยของร้านซ่อมคอมพิวเตอร์ชุมชน ตอบเรื่องอาการเสียและวิธีตรวจสอบเบื้องต้นเท่านั้น
> ห้ามเดารุ่นอุปกรณ์หรือราคา ถ้าไม่แน่ใจให้บอกว่า 'ต้องตรวจกับคู่มือ'
> ตอบเป็น 3 ส่วน: อาการ / สาเหตุที่เป็นไปได้ / วิธีตรวจสอบ"

## 7. ภารกิจที่ 5 — สร้าง "การ์ดผู้ช่วย AI" (25 คะแนน)

**นี่คือชิ้นงานสร้างสรรค์หลักของภารกิจ**

ออกแบบ **การ์ด 1 หน้า A4** (หรือสไลด์ 1 หน้า) แนะนำผู้ช่วย AI ที่นักเรียนสร้างขึ้น

### ต้องมีครบ 5 ส่วน

| ส่วน | รายละเอียด |
| :--- | :--- |
| **1. ชื่อและสโลแกน** | ตั้งชื่อ memorable + คำโปรย 1 ประโยค |
| **2. บทบาท** | ทำอาชีพอะไร ช่วยใคร แก้ปัญหาอะไร |
| **3. กฎ 3 ข้อ** | สิ่งที่ผู้ช่วยนี้ทำเสมอ / ห้ามทำเด็ดขาด |
| **4. ตัวอย่างบทสนทนา** | คำถาม 1 ข้อ + คำตอบที่ดีที่สุด 3–5 บรรทัด |
| **5. ข้อควรระวัง** | เรื่องที่ผู้ใช้ต้องตรวจสอบเอง 2 ข้อ |

> [!important] เกณฑ์ความคิดสร้างสรรค์
> * ชื่อต้อง **ไม่ซ้ำใครในห้อง** และสื่อบุคลิกได้
> * ต้องตอบโจทย์ **คนจริงในชุมชน/อาชีพจริง** ไม่ใช่เพื่อนในจินตนาการ
> * ห้ามใช้ชื่อแบรนด์หรือบุคคลจริงโดยไม่ได้รับอนุญาต
> * ต้องมีความ **ตลก/น่าจดจำ** ได้ แต่ต้องสุภาพและไม่ล้อเลียนบุคคล

### ตัวอย่าง (แนวคิด ไม่ใช่แบบฟอร์ม)

> **ชื่อ:** ช่างแจ๋ว ผู้ช่วยช่างแอร์ชุมชน
> **สโลแกน:** "แอร์ไม่เย็น? ถามก่อนเรียกช่าง"
> **กฎ 3 ข้อ:** ถามอาการก่อนเสนอวิธี / ห้ามบอกราคาจริง / ถ้าเป็นเรื่องไฟ ต้องส่งต่อช่างทันที
> **ตัวอย่างคำตอบ:** "ถ้าแอร์เปิดแต่ไม่เย็น ให้ตรวจ 3 อย่างนี้ก่อน: 1) ตั้งโหมด Cool หรือไม่ 2) ฟิลเตอร์ตันไหม 3) คอมเพรสเซอร์ทำงานหรือเปล่า..."

| :--- | :--- | :--- | :--- | :--- |
| **ภารกิจ 1** Token (15) | เปรียบเทียบครบ + จับได้ว่า AI เดา token | ครบแต่วิเคราะห์น้อย | ทำครบแต่ไม่มีข้อสรุป | ขาดหลักฐาน |
| **ภารกิจ 2** Context (15) | มีเส้นเวลา + อธิบายสาเหตุ | มีผลทดลองชัด | ทำแต่ไม่อธิบาย | ไม่ได้ทดลองจริง |
| **ภารกิจ 3** Hallucination (20) | ตารางครบ + สัญญาณอันตราย 3 ข้อคม | ครบแต่สัญญาณกว้าง | ตารางไม่ครบ | ไม่ได้ประดิษฐ์ของเอง |
| **ภารกิจ 4** System Prompt (25) | ครบ 6 องค์ประกอบ + เปรียบเทียบชัด | ครบ 6 แต่เปรียบเทียบน้อย | ขาด 1–2 องค์ประกอบ | prompt สั้นเกินไป |
| **ภารกิจ 5** การ์ด (25) | สร้างสรรค์ ใช้ได้จริง น่าจดจำ | ดีแต่ยังทั่วไป | ครบแต่ไม่มีเอกลักษณ์ | ขาดส่วนสำคัญ |
| **โบนัส** (5) | พบพฤติกรรม AI ที่น่าสนใจนอกเหนือโจทย์ และอธิบายได้ | อธิบายได้บางส่วน | พบแต่ไม่อธิบาย | — |

> [!warning] การหักคะแนน
> * ส่งช้ากว่ากำหนด: −10 คะแนน/วัน
> * คัดลอกงานเพื่อน: 0 คะแนนทั้งสองคน
> * มีข้อมูลส่วนบุคคลในภาพหน้าจอ: −5 คะแนน
> * ไม่มีหลักฐานภาพหน้าจอ: หักได้ถึง 30%

## 10. สำหรับครู (ไม่ต้องแจกนักเรียน)

> [!note] จุดที่ต้องเน้นตอนตรวจ
> 1. **ภารกิจ 1 ตอน B** — นักเรียนส่วนใหญ่จะตกใจว่า AI นับ token ผิด ให้ใช้จังหวะนี้อธิบายว่า "โมเดลเห็น token ไม่เห็นตัวอักษร"
> 2. **ภารกิจ 2** — คำตอบที่ถูกต้องคือ "AI ไม่เคยเก็บ" ไม่ใช่ "ลืม" (ยกเว้นเปิด Memory) — ถ้านักเรียนตอบถูกให้คะแนนพิเศษ
> 3. **ภารกิจ 3** — ตรวจว่าไม่ได้ใบ้ให้ AI รู้ว่าของปลอม มิฉะนั้นจะไม่ได้เห็นพฤติกรรมจริง
> 4. **ภารกิจ 4** — ตรวจว่ามีข้อห้าม "ถ้าไม่รู้ให้บอกไม่รู้" ซึ่งเป็นหัวใจของการลด hallucination

**คำถามเปิดวงอภิปรายในชั้นเรียน (สัปดาห์ที่ 2):**
* มีใครเจอ AI ที่ "ปฏิเสธที่จะตอบ" บ้าง? เพราะอะไร?
* ใครในการ์ดของเพื่อน จะเชื่อถือได้มากที่สุด ถ้าต้องใช้งานจริง?
* ถ้าต้องจ่ายเงินให้ AI ตามจำนวน token นักเรียนจะเขียน prompt ต่างจากเดิมไหม?

**ทางเลือกสำหรับนักเรียนที่ไม่มีบัญชี:**
ใช้เครื่องในห้อง TC203 (ลงชื่อใช้) หรือใช้ Gemini ผ่านบัญชี Google ของโรงเรียน
