## งานที่ 1 — ระบบคิดค่าบริการ API แบบขั้นบันได

> [!question] คำสั่ง
> บริษัทให้บริการ API คิดค่าบริการตามจำนวนครั้งที่เรียก (ต่อเดือน) แบบขั้นบันได
>
> | ช่วงจำนวนครั้ง | อัตราคิดเงิน |
> | :--- | :--- |
> | 1 – 1,000 | ฟรี |
> | 1,001 – 5,000 | ครั้งละ 0.10 บาท (คิดเฉพาะส่วนที่เกิน 1,000) |
> | 5,001 – 20,000 | ครั้งละ 0.06 บาท (คิดเฉพาะส่วนที่เกิน 5,000) |
> | 20,001 ขึ้นไป | ครั้งละ 0.04 บาท (คิดเฉพาะส่วนที่เกิน 20,000) |
>
> **ลำดับการคิด:** ค่าบริการ → ส่วนลดลูกค้าประจำ 10% → VAT 7% → ยอดรวม
>
> เงื่อนไขเพิ่มเติม
> - ถ้าจำนวนครั้งติดลบ ให้พิมพ์ `จำนวนครั้งต้องไม่ติดลบ` แล้วจบ (ไม่ต้องคำนวณ)
> - ถามว่าเป็นลูกค้าประจำหรือไม่ด้วย `y/n` (รับ `Y` หรือ `y` ก็ได้)
> - แสดงผลทศนิยม 2 ตำแหน่งและคั่นหลักพันทุกบรรทัด
>
> **ตัวอย่างที่ 1**
>
> ```text
> จำนวนการเรียก API: 3000
> ลูกค้าประจำ (y/n): n
> ค่าบริการ          200.00 บาท
> ส่วนลด              0.00 บาท
> ยอดก่อน VAT       200.00 บาท
> VAT 7%             14.00 บาท
> รวมทั้งสิ้น        214.00 บาท
> ```
>
> **ตัวอย่างที่ 2**
>
> ```text
> จำนวนการเรียก API: 10000
> ลูกค้าประจำ (y/n): Y
> ค่าบริการ          700.00 บาท
> ส่วนลด             70.00 บาท
> ยอดก่อน VAT       630.00 บาท
> VAT 7%             44.10 บาท
> รวมทั้งสิ้น        674.10 บาท
> ```
>
> **ค่าที่ต้องรันทดสอบ:** `800` (ไม่ประจำ) · `3000` (ไม่ประจำ) · `10000` (ประจำ) · `25000` (ประจำ) · `-5`

## งานที่ 2 — วันถัดไป

> [!question] คำสั่ง
> รับ วัน / เดือน / ปี (ค.ศ.) แล้วพิมพ์วันที่ถัดไปในรูปแบบ `วัน/เดือน/ปี`
>
> ต้องจัดการได้ครบทุกกรณี
> - เดือนที่มี 30 วัน: 4, 6, 9, 11
> - เดือนที่มี 31 วัน: 1, 3, 5, 7, 8, 10, 12
> - กุมภาพันธ์ 28 หรือ 29 วัน ตามปีอธิกสุรทิน (หาร 4 ลงตัว และไม่หาร 100 ลงตัว) หรือ (หาร 400 ลงตัว)
> - สิ้นเดือน → ขึ้นเดือนใหม่, 31 ธันวาคม → 1/1/ปีถัดไป
>
> **ต้องตรวจข้อมูลไม่ถูกต้องด้วย**
> - เดือนไม่อยู่ในช่วง 1–12 → `เดือนไม่ถูกต้อง`
> - วันที่ไม่อยู่ในช่วงของเดือนนั้น (เช่น 31/4, 29/2/2023) → `วันไม่ถูกต้อง — เดือน 4 มี 30 วัน`
>
> **ตัวอย่างผลรัน**
>
> ```text
> วัน: 28
> เดือน: 2
> ปี (ค.ศ.): 2024
> 29/2/2024
> ```
>
> ```text
> วัน: 31
> เดือน: 12
> ปี (ค.ศ.): 2023
> 1/1/2024
> ```
>
> ```text
> วัน: 31
> เดือน: 4
> ปี (ค.ศ.): 2024
> วันไม่ถูกต้อง — เดือน 4 มี 30 วัน
> ```
>
> **ค่าที่ต้องรันทดสอบ:** `31/1/2024` · `28/2/2023` · `28/2/2024` · `31/12/2025` · `30/4/2024` · `31/4/2024` · `29/2/2023` · `13/13/2024`

## งานที่ 3 — ตรวจหลักตรวจสอบรหัสสินค้า

> [!question] คำสั่ง
> รหัสสินค้าเป็นเลข 5 หลัก โดย 4 หลักแรกคือข้อมูล หลักที่ 5 คือ **หลักตรวจสอบ (Check Digit)**
>
> วิธีคำนวณหลักตรวจสอบ
> 1. นำหลักที่ 1–4 คูณน้ำหนัก 5, 4, 3, 2 ตามลำดับ แล้วบวกกันเป็น `total`
> 2. `expected = total % 11` (ค่าที่ได้เป็น 0–10)
> 3. ถ้า `expected` เท่ากับหลักที่ 5 → รหัสถูกต้อง
>
> เงื่อนไขเพิ่มเติม
> - ถ้ารหัสไม่ครบ 5 หลัก (น้อยกว่า 10000 หรือมากกว่า 99999) → `รหัสต้องมี 5 หลัก`
> - ถ้ารหัสผิด ให้บอกว่าหลักตรวจสอบที่ถูกต้องควรเป็นเท่าไร
>
> **ตัวอย่างผลรัน**
>
> ```text
> รหัสสินค้า 5 หลัก: 24132
> รหัส 24132 ถูกต้อง
> ```
>
> ```text
> รหัสสินค้า 5 หลัก: 12345
> รหัส 12345 ไม่ถูกต้อง — หลักตรวจควรเป็น 8
> ```
>
> **ค่าที่ต้องรันทดสอบ:** `24132` · `12345` · `12300` · `99999` · `842`

> [!danger] เปิดหลังทำเสร็จเท่านั้น

### เฉลยงานที่ 1

```python
# challenge1.py
calls = int(input("จำนวนการเรียก API: "))

if calls < 0:
    print("จำนวนครั้งต้องไม่ติดลบ")
else:
    if calls <= 1000:
        usage = 0.00
    elif calls <= 5000:
        usage = (calls - 1000) * 0.10
    elif calls <= 20000:
        usage = 4000 * 0.10 + (calls - 5000) * 0.06
    else:
        usage = 4000 * 0.10 + 15000 * 0.06 + (calls - 20000) * 0.04

    is_member = input("ลูกค้าประจำ (y/n): ").lower() == "y"

    if is_member:
        discount = usage * 0.10
    else:
        discount = 0.00

    net = usage - discount
    vat = net * 0.07
    total = net + vat

    print(f"ค่าบริการ      {usage:>10,.2f} บาท")
    print(f"ส่วนลด         {discount:>10,.2f} บาท")
    print(f"ยอดก่อน VAT    {net:>10,.2f} บาท")
    print(f"VAT 7%         {vat:>10,.2f} บาท")
    print(f"รวมทั้งสิ้น    {total:>10,.2f} บาท")
```

**ผลรัน `calls=25000`, ประจำ** → `ใช้ 1,500.00 → ลด 150.00 → ก่อน VAT 1,350.00 → VAT 94.50 → รวม 1,444.50`

### เฉลยงานที่ 2

```python
# challenge2.py
d = int(input("วัน: "))
m = int(input("เดือน: "))
y = int(input("ปี (ค.ศ.): "))

if m < 1 or m > 12:
    print("เดือนไม่ถูกต้อง")
else:
    if m == 2:
        if (y % 4 == 0 and y % 100 != 0) or y % 400 == 0:
            max_day = 29
        else:
            max_day = 28
    elif m == 4 or m == 6 or m == 9 or m == 11:
        max_day = 30
    else:
        max_day = 31

    if d < 1 or d > max_day:
        print(f"วันไม่ถูกต้อง — เดือน {m} มี {max_day} วัน")
    elif d < max_day:
        print(f"{d + 1}/{m}/{y}")
    elif m < 12:
        print(f"1/{m + 1}/{y}")
    else:
        print(f"1/1/{y + 1}")
```

### เฉลยงานที่ 3

```python
# challenge3.py
code = int(input("รหัสสินค้า 5 หลัก: "))

if code < 10000 or code > 99999:
    print("รหัสต้องมี 5 หลัก")
else:
    d1 = code // 10000
    d2 = code // 1000 % 10
    d3 = code // 100 % 10
    d4 = code // 10 % 10
    d5 = code % 10

    total = d1 * 5 + d2 * 4 + d3 * 3 + d4 * 2
    expected = total % 11

    if expected == d5:
        print(f"รหัส {code} ถูกต้อง")
    else:
        print(f"รหัส {code} ไม่ถูกต้อง — หลักตรวจควรเป็น {expected}")
```
