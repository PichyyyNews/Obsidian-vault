## 2. ขั้นที่ 1 — ติดตั้ง Python (Windows)

### 2.1 ดาวน์โหลด

1. เปิดเบราว์เซอร์ไปที่ **`python.org`**
2. เมนู **Downloads** → **Windows**
3. เลือกเวอร์ชัน **Python 3.x** (เช่น 3.12 หรือ 3.13) แบบ 64-bit
4. ดับเบิลคลิกไฟล์ที่ดาวน์โหลด

> [!danger] จุดที่พลาดบ่อยที่สุด
> หน้าแรกของตัวติดตั้งมีช่อง **"Add python.exe to PATH"** อยู่ด้านล่าง
> **ต้องติ๊กก่อนกด Install** ไม่อย่างนั้นจะเรียก `python` จาก Terminal ไม่ได้

### 2.2 ติดตั้ง

1. ติ๊ก **Add python.exe to PATH**
2. คลิก **Install Now**
3. รอจนขึ้น **Setup was successful**
4. ปิดหน้าต่างติดตั้ง

### 2.3 ตรวจสอบว่าติดตั้งสำเร็จ

เปิด **Command Prompt** (กด `Win + R` → พิมพ์ `cmd` → Enter) แล้วพิมพ์

```text
python --version
```

ถ้าขึ้นแบบ `Python 3.12.x` แปลว่าสำเร็จ

ถ้าขึ้นว่า `'python' is not recognized` ให้ลอง

```text
py --version
```

ถ้า `py` ใช้ได้แต่ `python` ไม่ได้ แปลว่าลืมติ๊ก PATH — วิธีแก้ที่เร็วที่สุดคือติดตั้งใหม่แล้วติ๊กช่องนั้น

> [!tip] ทางเลือกสำหรับห้องแล็บ
> ถ้าเครื่องในห้องติดตั้ง Python ไว้แล้ว ให้ข้ามไปข้อ 3 ได้เลย
> แต่ควรตรวจเวอร์ชันให้ตรงกันทั้งห้อง เพื่อไม่ให้โค้ดบางคำสั่งใช้ได้ไม่เหมือนกัน

## 3. ขั้นที่ 2 — ติดตั้ง VS Code และตั้งค่า

### 3.1 ติดตั้งโปรแกรม

1. ไปที่ **`code.visualstudio.com`**
2. ดาวน์โหลดเวอร์ชัน **Windows (User Installer)**
3. ติดตั้งตามค่าเริ่มต้น
4. เปิดโปรแกรมขึ้นมา

### 3.2 ติดตั้ง Extension ที่จำเป็น

1. คลิกไอคอน **Extensions** ด้านซ้าย (รูปสี่เหลี่ยม 4 ชิ้น)
2. ค้นหา **`Python`** (ผู้พัฒนา: Microsoft)
3. กด **Install**
4. (แนะนำ) ติดตั้ง **`Pylance`** เพิ่ม เพื่อช่วยตรวจโค้ด

### 3.3 สร้างโฟลเดอร์ทำงาน

1. สร้างโฟลเดอร์ เช่น `D:\python_basic`
2. ใน VS Code เลือก **File → Open Folder** แล้วเลือกโฟลเดอร์นี้
3. สร้างไฟล์ใหม่ชื่อ **`hello.py`**

> [!warning] ห้ามตั้งชื่อไฟล์ว่า `python.py`
> เพราะจะไปชนกับชื่อโมดูลมาตรฐานของ Python ทำให้โปรแกรมทำงานผิดพลาด
> ตั้งชื่อสื่อความหมาย เช่น `hello.py`, `lab_a.py`, `invoice.py`

## 4. ขั้นที่ 3 — โปรแกรมแรก และการรัน 3 วิธี

### 4.1 เขียนโค้ดแรก

พิมพ์ในไฟล์ `hello.py`

```python
# โปรแกรมแรกของฉัน
print("Hello, Computer Technology!")
print("ฉันกำลังเรียนภาษา Python")
```

### 4.2 รันด้วยปุ่ม Run (วิธีที่ใช้บ่อยที่สุด)

1. กด **Ctrl + S** เพื่อบันทึก
2. กดปุ่ม **▶ Run** มุมขวาบน หรือกด **Ctrl + F5**
3. ดูผลลัพธ์ที่แผง **Terminal** ด้านล่าง

ผลลัพธ์ที่ควรเห็น

```text
Hello, Computer Technology!
ฉันกำลังเรียนภาษา Python
```

### 4.3 รันด้วย Terminal (วิธีที่นักพัฒนาจริงใช้)

1. เปิด Terminal ใน VS Code (**Terminal → New Terminal**)
2. ตรวจว่าอยู่ในโฟลเดอร์ที่มีไฟล์
3. พิมพ์

```text
python hello.py
```

### 4.4 รันด้วย IDLE (มีมาให้กับ Python)

1. กด `Win` → ค้นหา **IDLE (Python)**
2. เปิดไฟล์ผ่าน **File → Open**
3. กด **F5** เพื่อรัน

> [!note] ทั้ง 3 วิธีได้ผลเหมือนกัน
> ต่างกันที่ความสะดวก — ในห้องเรียนใช้ปุ่ม Run, ตอนส่งงาน/ทำงานจริงใช้ Terminal, และ IDLE ใช้เมื่อเครื่องไม่มี VS Code

### 4.5 ถ้ารันแล้วไม่ขึ้นอะไร

| อาการ | สาเหตุ | วิธีแก้ |
| :--- | :--- | :--- |
| Terminal ขึ้น `python: command not found` | ไม่ได้เพิ่ม PATH | ติดตั้งใหม่ ติ๊ก Add to PATH |
| ขึ้น `can't open file ... No such file` | อยู่ผิดโฟลเดอร์ | `cd` ไปโฟลเดอร์ที่มีไฟล์ |
| ไม่มีอะไรเกิดขึ้นเลย | ยังไม่บันทึกไฟล์ | กด Ctrl+S แล้วรันใหม่ |
| ขึ้น `SyntaxError` | พิมพ์ผิด เช่น ลืมเครื่องหมายคำพูด | ดูบรรทัดที่ error บอก |

## 5. ขั้นที่ 4 — กฎพื้นฐานของไฟล์ Python

### 5.1 คอมเมนต์ (Comment)

```python
# นี่คือคอมเมนต์บรรทัดเดียว ตัวแปลภาษาจะข้ามไป

"""
นี่คือ Docstring
ใช้เขียนคำอธิบายหลายบรรทัด
"""
print("โปรแกรมยังทำงานปกติ")
```

### 5.2 การย่อหน้า (Indentation)

Python ใช้ **การย่อหน้า** กำหนดขอบเขตของบล็อกคำสั่ง ไม่ใช้ปีกกา `{ }`

```python
# ถูกต้อง: ย่อหน้า 4 เคาะ
if True:
    print("อยู่ในบล็อก")

# ผิด: ไม่ย่อหน้า
if True:
print("จะเกิด IndentationError")
```

> [!warning] กฎที่ต้องจำ
> * ใช้ **Space 4 เคาะ** ตามมาตรฐาน PEP 8
> * **ห้ามผสม Tab กับ Space** ในไฟล์เดียวกัน
> * VS Code ตั้งค่า Tab เป็น Space ให้อัตโนมัติอยู่แล้ว

### 5.3 ตัวพิมพ์เล็ก–ใหญ่

```python
name = "สมชาย"
Name = "สมหญิง"

print(name)   # สมชาย
print(Name)   # สมหญิง
```

`name` กับ `Name` เป็นคนละตัวแปร

## 6. ขั้นที่ 5 — ตัวแปร: ป้ายชื่อ ไม่ใช่กล่อง

### 6.1 แนวคิดสำคัญ

ในภาษา C ตัวแปรคือ "กล่อง" ที่จองที่ในหน่วยความจำ
แต่ใน Python **ทุกอย่างคืออ็อบเจกต์** และตัวแปรเป็นเพียง **ป้ายชื่อ (Name Tag)** ที่ชี้ไปยังอ็อบเจกต์นั้น

```python
x = 100
print(id(x))   # ตำแหน่งของอ็อบเจกต์ 100
print(type(x)) # <class 'int'>

x = 200
print(id(x))   # ตำแหน่งเปลี่ยนไป (หรืออาจเป็นตำแหน่งใหม่)
```

> [!note] ทำไมต้องรู้เรื่องนี้
> เพราะอธิบายได้ว่าทำไม `a = b` ไม่ได้ "ก๊อปค่า" เสมอไปในโครงสร้างข้อมูลซับซ้อน (จะเจอชัดในสัปดาห์ที่ 10 เรื่อง List)

### 6.2 การตั้งชื่อตัวแปร (PEP 8)

| กฎ | ตัวอย่างถูก | ตัวอย่างผิด |
| :--- | :--- | :--- |
| ขึ้นต้นด้วยตัวอักษรหรือ `_` | `cpu_temp` | `2cpu` |
| ใช้ตัวพิมพ์เล็กและ `_` คั่น | `total_price` | `TotalPrice` |
| ห้ามใช้คำสงวน | `score` | `for`, `if`, `class` |
| สื่อความหมาย | `download_speed` | `a`, `x1` |

### 6.3 การกำหนดค่าหลายตัวแปรพร้อมกัน

```python
cpu, ram, ssd = "i5", 16, 512
print(cpu, ram, ssd)

# สลับค่าแบบไม่ต้องใช้ตัวแปรชั่วคราว
a, b = 1, 2
a, b = b, a
print(a, b)   # 2 1
```

### 6.4 ค่าคงที่ (Constant)

Python ไม่มีคำสั่ง const แต่ใช้ **ชื่อตัวพิมพ์ใหญ่ทั้งหมด** เป็นธรรมเนียม

```python
VAT_RATE = 0.07
MAX_RETRY = 3
```

## 7. ขั้นที่ 6 — ชนิดข้อมูลพื้นฐาน

| ชนิด | ชื่อ | ตัวอย่าง | ใช้กับ |
| :--- | :--- | :--- | :--- |
| จำนวนเต็ม | `int` | `10`, `-3`, `0` | นับจำนวน, พอร์ต |
| ทศนิยม | `float` | `3.14`, `0.5` | ราคา, อุณหภูมิ |
| ข้อความ | `str` | `"CPU"`, `'i5'` | ชื่อ, ข้อความ |
| ตรรกะ | `bool` | `True`, `False` | สถานะเปิด/ปิด |

```python
print(type(10))      # <class 'int'>
print(type(3.14))    # <class 'float'>
print(type("CPU"))   # <class 'str'>
print(type(True))    # <class 'bool'>
```

### 7.1 กับดักของ float

```python
print(0.1 + 0.2)
# 0.30000000000000004
```

เกิดจากข้อจำกัดของการเก็บเลขฐานสอง — ไม่ใช่บั๊กของ Python
ถ้าต้องการทศนิยมสวย ๆ ให้ใช้ `round()` หรือ `f"{value:.2f}"`

### 7.2 กับดักการบวกข้อความกับตัวเลข

```python
age = 18
print("อายุ " + age)      # TypeError
print("อายุ " + str(age)) # ถูกต้อง
print(f"อายุ {age}")      # ดีที่สุด
```

> [!tip] กฎง่าย ๆ
> `+` ใช้ได้กับ **ชนิดเดียวกัน** เท่านั้น
> ถ้าเป็นข้อความกับตัวเลข ให้ใช้ `str()` แปลง หรือใช้ f-string

## 8. ขั้นที่ 7 — รับข้อมูลด้วย `input()` และแปลงชนิด

### 8.1 กับดักที่สำคัญที่สุด

```python
age = input("อายุของคุณ: ")
print(type(age))   # <class 'str'> เสมอ!
```

`input()` คืนค่าเป็น **ข้อความ (str) ทุกครั้ง** แม้ผู้ใช้จะพิมพ์ตัวเลข

### 8.2 การแปลงชนิด (Type Casting)

```python
age = int(input("อายุของคุณ: "))
height = float(input("ส่วนสูง (ซม.): "))
name = input("ชื่อ: ")          # ไม่ต้องแปลง เพราะเป็นข้อความอยู่แล้ว

print(f"สวัสดี {name} อายุ {age} ปี สูง {height} ซม.")
```

| ฟังก์ชัน | แปลงเป็น | ตัวอย่าง |
| :--- | :--- | :--- |
| `int()` | จำนวนเต็ม | `int("25")` → `25` |
| `float()` | ทศนิยม | `float("3.5")` → `3.5` |
| `str()` | ข้อความ | `str(42)` → `"42"` |
| `bool()` | ตรรกะ | `bool(0)` → `False` |

> [!warning] ถ้าผู้ใช้พิมพ์ผิด
> `int("abc")` จะเกิด **ValueError** และโปรแกรมหยุดทันที
> การดักจับด้วย `try/except` จะเรียนในสัปดาห์ที่ 14 — ตอนนี้ให้ตรวจข้อมูลง่าย ๆ ด้วย `.isdigit()`

```python
text = input("จำนวน: ")
if text.isdigit():
    number = int(text)
    print(number * 2)
else:
    print("กรุณาพิมพ์ตัวเลขเท่านั้น")
```

> [!note] ยังไม่ต้องเขียน `if` เป็น
> ตัวอย่างข้างบนใช้ `if` ล่วงหน้าเพื่อให้เห็นภาพรวม — คำสั่งเงื่อนไขจะเรียนเต็ม ๆ ใน**สัปดาห์ที่ 5**
> ในสัปดาห์นี้ให้จดจำแค่ว่า "ถ้าข้อมูลไม่ใช่ตัวเลข แล้วเอาไป `int()` จะพัง"

## 9. ขั้นที่ 8 — ตัวดำเนินการทางคณิตศาสตร์

| ตัวดำเนินการ | ความหมาย | ตัวอย่าง | ผลลัพธ์ |
| :--: | :--- | :--- | :--: |
| `+` | บวก | `7 + 2` | 9 |
| `-` | ลบ | `7 - 2` | 5 |
| `*` | คูณ | `7 * 2` | 14 |
| `/` | หาร (ได้ทศนิยมเสมอ) | `7 / 2` | 3.5 |
| `//` | หารปัดลง | `7 // 2` | 3 |
| `%` | เศษจากการหาร | `7 % 2` | 1 |
| `**` | ยกกำลัง | `2 ** 10` | 1024 |

### 9.1 ลำดับความสำคัญ (Precedence)

```text
1. ( )          วงเล็บ
2. **           ยกกำลัง
3. +x  -x       เครื่องหมายบวก/ลบ
4. *  /  //  %  คูณ หาร
5. +  -         บวก ลบ
```

```python
print(2 + 3 * 4)     # 14 (คูณก่อน)
print((2 + 3) * 4)   # 20 (วงเล็บก่อน)
print(2 ** 3 ** 2)   # 512 (ยกกำลังขวาสุดก่อน)
```

### 11.1 ใบงาน A — คำนวณพื้นที่ใช้งาน RAID 5

**โจทย์:** รับขนาดดิสก์ลูกเดียว (GB) และจำนวนลูก แล้วคำนวณพื้นที่ใช้งานจริงของ RAID 5 ซึ่งเสียพื้นที่ 1 ลูกสำหรับ parity

```python
# lab_a_raid5.py
disk_gb = float(input("ขนาดดิสก์ลูกเดียว (GB): "))
disk_count = int(input("จำนวนดิสก์ (ลูก): "))

usable = (disk_count - 1) * disk_gb

print(f"พื้นที่ใช้งานได้: {usable:,.2f} GB")
print(f"พื้นที่สูญเสีย (parity): {disk_gb:,.2f} GB")
```

```python
# lab_b_power_cost.py
```

### 11.3 ใบงาน C — ใบเสร็จร้านคอมพิวเตอร์

**โจทย์:** รับชื่อสินค้า 3 รายการ พร้อมจำนวนและราคาต่อหน่วย แล้วแสดงใบเสร็จพร้อม VAT 7%

```python
# lab_c_invoice.py
VAT_RATE = 0.07

name1 = input("สินค้าที่ 1: ")
qty1 = int(input("จำนวน: "))
price1 = float(input("ราคาต่อหน่วย: "))

vat = subtotal * VAT_RATE
grand_total = subtotal + vat

print("=" * 36)
print(f'{"สินค้า":<14}{"จำนวน":>6}{"รวม":>14}')
```

### 11.4 ใบงาน D — เวลาในการดาวน์โหลดไฟล์

**โจทย์:** รับขนาดไฟล์ (GB) และความเร็วเน็ต (Mbps) แล้วคำนวณเวลาเป็นนาทีและวินาที

```python
# lab_d_download.py
size_gb = float(input("ขนาดไฟล์ (GB): "))
speed_mbps = float(input("ความเร็วเน็ต (Mbps): "))

size_mb = size_gb * 1024
size_mbit = size_mb * 8
seconds = size_mbit / speed_mbps

minutes = int(seconds // 60)
remain = seconds % 60

print(f"ขนาดไฟล์: {size_mbit:,.0f} Mb")
print(f"เวลาโดยประมาณ: {minutes} นาที {remain:.2f} วินาที")
```

**ตัวอย่าง**

```text
ขนาดไฟล์ (GB): 8
ความเร็วเน็ต (Mbps): 100
ขนาดไฟล์: 65,536 Mb
เวลาโดยประมาณ: 10 นาที 55.36 วินาที
```

> [!note] จุดที่ต้องสังเกต
> `8 GB = 8 × 1024 = 8192 MB` และ `1 MB = 8 Mb`
> ดังนั้น `8192 × 8 = 65,536 Mb` — ตัวเลขนี้คือจุดที่นักเรียนสับสนบ่อยที่สุด
