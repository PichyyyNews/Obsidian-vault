> - ถ้าใช้ความรู้เดิม เราต้องสร้างตัวแปรชื่อ `score1`, `score2`, `score3`, ..., `score40` ทั้งหมด 40 ตัว!

>
> ในโลกการเขียนโปรแกรม จึงมีการสร้างตัวแปรแบบ **"กล่องเก็บข้อมูลเป็นชุด"** ขึ้นมา ภาษาอื่น (เช่น C, Java) จะเรียกว่า **Array (อาร์เรย์)** ส่วนในภาษา Python เราจะใช้สิ่งที่เรียกว่า **`List` (ลิสต์)** ซึ่งทำหน้าที่เหมือน Array ที่เก่งและยืดหยุ่นกว่ามาก และเมื่อจับคู่ **`List` + `Loop`** เราจะสามารถจัดการข้อมูลเป็นร้อยเป็นพันตัวได้ด้วยโค้ดแค่ไม่กี่บรรทัดครับ

## ส่วนที่ 1: แนวคิด Array และความหมายของ `List` ใน Python

### 1.1 Array กับ `List` เหมือนหรือต่างกันอย่างไร?

หากนักศึกษาเคยได้ยินคำว่า **Array (อาร์เรย์ / ตัวแปรชุด)** จากภาษา C หรือ Java ให้เข้าใจตรงกันดังนี้ครับ:

- **Array ในภาษา C/Java:** เป็นแถวของช่องเก็บข้อมูลเรียงต่อกัน ต้องกำหนดขนาดล่วงหน้า (เช่น จองไว้ 10 ช่อง) และทุกช่องต้องเก็บข้อมูล **ชนิดเดียวกันล้วน ๆ**
- **`List` ในภาษา Python:** ทำหน้าที่เป็น **Dynamic Array** (อาร์เรย์แบบยืดหยุ่น) ซึ่งคนเขียน Python ใช้เป็นหลักกว่า 95% ของงานทั้งหมด โดยมีข้อดีเหนือกว่า Array ทั่วไปคือ:
  1. **ขยายขนาดเองได้อัตโนมัติ** อยากเพิ่มหรือลบกี่ตัวก็ได้ ไม่ต้องจองขนาดล่วงหน้า
  2. **เก็บข้อมูลคละชนิดในตัวแปรเดียวได้** (เช่น เก็บทั้งข้อความ ตัวเลข และ Boolean ปนกันได้)
  3. **มีคำสั่งสำเร็จรูปในตัวเพียบ** เช่น เรียงลำดับ กลับด้าน ค้นหา เพิ่ม/ลบ

*(หมายเหตุ: ใน Python ก็มีโมดูลชื่อ `import array` อยู่จริง สำหรับงานที่ต้องการล็อกชนิดข้อมูลให้เหมือนกันล้วน ๆ เพื่อประหยัด RAM แต่ในการเขียนโปรแกรมทั่วไป เราจะใช้ `List` เป็นมาตรฐานหลัก)*

### 1.2 วิธีสร้าง `List` และการนับจำนวนสมาชิก

การสร้าง `List` ในไพธอนจะใช้เครื่องหมาย **วงเล็บก้ามปู `[ ]`** และคั่นสมาชิกแต่ละตัวด้วยเครื่องหมายจุลภาค `,`

```python
# 1. List เก็บตัวเลข
scores = [85, 72, 90, 64, 78]

# 2. List เก็บข้อความ (String)
devices = ["CPU", "RAM", "SSD", "GPU"]

# 3. List เก็บข้อมูลคละชนิด (รหัสสินค้า, ชื่อ, ราคา, สถานะพร้อมขาย)
product = ["P001", "สาย LAN Cat6", 150.50, True]

# 4. List ว่าง (เอาไว้รอรับข้อมูลเพิ่มทีหลัง)
cart = []

print(devices)             # ผลลัพธ์: ['CPU', 'RAM', 'SSD', 'GPU']
print(len(devices))        # ใช้ len() นับจำนวนสมาชิก -> ผลลัพธ์: 4
```

## ส่วนที่ 2: การเข้าถึงข้อมูลใน `List` (Indexing & Slicing)

ข้อมูลใน `List` จะถูกเรียงลำดับเป็นช่อง ๆ โดยแต่ละช่องจะมี **"เลขประจำตำแหน่ง" เรียกว่า `Index` (อินเด็กซ์)**

### 2.1 การอ้างอิงตำแหน่งด้วย Index (จำไว้: เริ่มที่ `0` เสมอ!)

สมมติเรามี `devices = ["CPU", "RAM", "SSD", "GPU"]` (มี 4 ตัว) โครงสร้างตำแหน่งในหน่วยความจำจะเป็นแบบนี้:

| ข้อมูล (Value) | `"CPU"` | `"RAM"` | `"SSD"` | `"GPU"` |
| :--- | :---: | :---: | :---: | :---: |
| **Index บวก (นับจากซ้าย)** | `0` | `1` | `2` | `3` |
| **Index ลบ (นับจากขวา)** | `-4` | `-3` | `-2` | `-1` |

```python
devices = ["CPU", "RAM", "SSD", "GPU"]

# เข้าถึงด้วย Index บวก (เริ่มจาก 0)
print(devices[0])    # CPU (ตัวแรก)
print(devices[2])    # SSD (ตัวที่ 3)

# เข้าถึงด้วย Index ลบ (นับถอยหลังจากตัวท้าย)
print(devices[-1])   # GPU (ตัวสุดท้ายเสมอ!)
print(devices[-2])   # SSD (ตัวรองสุดท้าย)
```

> [!CAUTION] ข้อผิดพลาดยอดฮิต: `IndexError: list index out of range`
> ถ้า List มีสมาชิก 4 ตัว (`len` = 4) เลข Index สูงสุดที่มีอยู่คือ **`3`** (ไม่ใช่ `4`)
> หากเราสั่ง `print(devices[4])` โปรแกรมจะแครชและขึ้น Error ทันที เพราะไม่มีช่องหมายเลข 4 อยู่จริง

---

### 2.2 การตัดแบ่งช่วงข้อมูล (List Slicing)

ถ้าต้องการหยิบข้อมูลออกมา **"หลายตัวติดกัน"** ให้ใช้เครื่องหมายโคลอน `:` ระบุช่วงดังนี้:

`ชื่อลิสต์[start : stop]` $\rightarrow$ หยิบตั้งแต่ตำแหน่ง `start` ไปจนถึง **ก่อนถึง** ตำแหน่ง `stop` (เหมือน `range()` เป๊ะ!)

```python
ports = [21, 22, 23, 80, 443, 3306]
# Index: 0   1   2   3    4     5

print(ports[1:4])    # เอา Index 1, 2, 3 -> [22, 23, 80]
print(ports[:3])     # ไม่ใส่ตัวหน้า = เริ่มจาก 0 ถึงก่อน 3 -> [21, 22, 23]
print(ports[3:])     # ไม่ใส่ตัวหลัง = เริ่มจาก 3 จนจบตัวสุดท้าย -> [80, 443, 3306]
```

## ส่วนที่ 3: การแก้ไข เพิ่ม และลบข้อมูลใน `List`

`List` มีคุณสมบัติเป็น **Mutable** (เปลี่ยนแปลงแก้ไขค่าข้างในได้ตลอดเวลา)

### 3.1 การแก้ไขค่าในตำแหน่งที่ต้องการ
อ้างอิงช่อง Index แล้วใช้เครื่องหมาย `=` กำหนดค่าใหม่ทับลงไปได้เลย:

```python
devices = ["CPU", "RAM", "HDD", "GPU"]
devices[2] = "NVMe SSD"    # เปลี่ยนช่องที่ 2 จาก HDD เป็น NVMe SSD
print(devices)             # ['CPU', 'RAM', 'NVMe SSD', 'GPU']
```

---

### 3.2 การเพิ่มข้อมูลเข้าสู่ `List`

| คำสั่ง (Method) | หน้าที่ | ตัวอย่างการใช้งาน | ผลลัพธ์ |
| :--- | :--- | :--- | :--- |
| **`.append(ค่า)`** | เพิ่มสมาชิกใหม่ไป **ต่อท้ายสุด** | `a = [10, 20]`<br>`a.append(30)` | `[10, 20, 30]` |
| **`.insert(ตำแหน่ง, ค่า)`** | **แทรก** สมาชิกเข้าไปในช่องที่ระบุ (ตัวหลังขยับหลบ) | `a = [10, 30]`<br>`a.insert(1, 20)` | `[10, 20, 30]` |
| **`.extend(ลิสต์อื่น)`** | นำสมาชิกของอีก List มาต่อท้ายทั้งหมด | `a = [1, 2]`<br>`a.extend([3, 4])` | `[1, 2, 3, 4]` |

---

### 3.3 การลบข้อมูลออกจาก `List`

| คำสั่ง | หน้าที่ | ตัวอย่างการใช้งาน | ผลลัพธ์ |
| :--- | :--- | :--- | :--- |
| **`.remove(ค่า)`** | ลบโดยอ้างอิงจาก **"ชื่อ/ค่า"** (ลบตัวแรกที่เจอ) | `x = ["A", "B", "C"]`<br>`x.remove("B")` | `["A", "C"]` |
| **`.pop(ตำแหน่ง)`** | ลบโดยอ้างอิงจาก **Index** และคืนค่าที่ลบออกมาได้ | `x = ["A", "B", "C"]`<br>`x.pop(0)` | ลบ `"A"` เหลือ `["B", "C"]` |
| **`.pop()`** | *(ไม่ใส่เลข)* ลบ **ตัวสุดท้าย** ออก | `x = ["A", "B", "C"]`<br>`x.pop()` | ลบ `"C"` เหลือ `["A", "B"]` |
| **`.clear()`** | ล้างข้อมูลทั้งหมดให้เป็น List ว่าง `[]` | `x.clear()` | `[]` |

### 3.4 คำสั่งตัวช่วยยอดนิยมที่ใช้กับ `List`

```python
nums = [40, 10, 90, 20]

# 1. เรียงลำดับข้อมูล (Sort)
nums.sort()                 # เรียงน้อย -> มาก: [10, 20, 40, 90]
nums.sort(reverse=True)     # เรียงมาก -> น้อย: [90, 40, 20, 10]

# 2. คำนวณค่าสถิติพื้นฐาน (ใช้กับ List ตัวเลข)
print("จำนวนตัว:", len(nums))    # 4
print("ผลรวม:", sum(nums))       # 160
print("ค่ามากสุด:", max(nums))   # 90
print("ค่าน้อยสุด:", min(nums))  # 10

# 3. ตรวจสอบว่ามีข้อมูลนี้อยู่ใน List ไหม (ใช้คำสั่ง in)
tools = ["ไขควง", "มัลติมิเตอร์", "คีมย้ำหัวแลน"]
if "มัลติมิเตอร์" in tools:
    print("พบอุปกรณ์ในคลัง!")
```

## ส่วนที่ 4: การนำ `Loop` มาใช้งานร่วมกับ `List` (หัวใจสำคัญ!)

พอเรามีข้อมูลเก็บเป็นชุดใน `List` แล้ว เราคงไม่มานั่งพิมพ์ `print(list[0])`, `print(list[1])`, ... ทีละบรรทัดแน่ ๆ — นี่คือจุดที่ **`for` loop** และ **`while` loop** เข้ามาทำงานร่วมกับ `List` อย่างเต็มรูปแบบ

### 4.1 รูปแบบที่ 1: วนหยิบข้อมูลทีละตัวโดยตรง (`for item in my_list:`)

เป็นวิธีที่ **ง่ายและอ่านคล่องที่สุด** เหมาะสำหรับตอนที่ต้องการหยิบค่าแต่ละตัวมาแสดงผลหรือคำนวณ

```python
devices = ["Router", "Switch", "Server", "Access Point"]

for item in devices:
    print("กำลังตรวจสอบสถานะ:", item)
```
**ผลลัพธ์:**
```text
กำลังตรวจสอบสถานะ: Router
กำลังตรวจสอบสถานะ: Switch
กำลังตรวจสอบสถานะ: Server
กำลังตรวจสอบสถานะ: Access Point
```

---

### 4.2 รูปแบบที่ 2: วนตามเลข Index (`for i in range(len(my_list)):`)

บางครั้งเราจำเป็นต้องรู้ว่าข้อมูลตัวนั้นอยู่ **"ลำดับที่เท่าไหร่"** หรือต้องการ **แก้ไขค่าข้างใน List** เราจะใช้ `range(len(...))` ช่วยสร้างเลข Index `0, 1, 2, ...`

```python
prices = [100, 200, 300]

# ตัวอย่าง: ต้องการบวก VAT หรือเพิ่มราคาสินค้าทุกชิ้นใน List ขึ้น 10 บาท
for i in range(len(prices)):
    prices[i] = prices[i] + 10
    print(f"สินค้าช่องที่ {i} ปรับราคาใหม่เป็น {prices[i]} บาท")
```
**ผลลัพธ์:**
```text
สินค้าช่องที่ 0 ปรับราคาใหม่เป็น 110 บาท
สินค้าช่องที่ 1 ปรับราคาใหม่เป็น 210 บาท
สินค้าช่องที่ 2 ปรับราคาใหม่เป็น 310 บาท
```

---

### 4.3 รูปแบบที่ 3: อยากได้ทั้งเลขลำดับและค่าในคำสั่งเดียว (`enumerate`)

Python มีฟังก์ชัน `enumerate()` ที่ช่วยแจกทั้งเลข Index และค่าสมาชิกพร้อมกัน ทำให้โค้ดสะอาดกว่าเดิม:

```python
students = ["สมชาย", "สมหญิง", "นนท์"]

for idx, name in enumerate(students, start=1):
    print(f"คนที่ {idx}: {name}")
```
**ผลลัพธ์:**
```text
คนที่ 1: สมชาย
คนที่ 2: สมหญิง
คนที่ 3: นนท์
```

### 4.4 รูปแบบที่ 4: ใช้ `while` loop รับข้อมูลจากผู้ใช้มาเก็บใน `List`

ในงานจริง เรามักไม่รู้ว่าผู้ใช้จะกรอกข้อมูลกี่ตัว จึงต้องใช้ **`while True:` + `.append()`** เพื่อเก็บข้อมูลเข้า List ไปเรื่อย ๆ จนกว่าผู้ใช้จะสั่งหยุด แล้วค่อยใช้ **`for` loop** วนประมวลผลทีหลัง

```python
# โปรแกรมรับรายการอะไหล่ที่ต้องการเบิก (ไม่จำกัดจำนวน)
order_list = []

while True:
    part = input("กรอกชื่ออะไหล่ (พิมพ์ 'done' เพื่อจบ): ")
    if part == "done":
        break
    order_list.append(part)   # เพิ่มข้อมูลต่อท้าย List เรื่อย ๆ

print("\n--- สรุปรายการเบิกอะไหล่ ---")
for i, item in enumerate(order_list, start=1):
    print(f"{i}. {item}")
print(f"รวมทั้งหมด {len(order_list)} รายการ")
```

## ส่วนที่ 5: ตัวอย่างการประยุกต์ใช้งานจริง (`List` + `Loop` + `if`)

### ตัวอย่างที่ 1: ระบบตรวจเช็กอุณหภูมิ CPU และคัดกรองเครื่องที่ร้อนเกินเกณฑ์
*(รวม `List` + `for` + `if` + ตัวนับ)*

```python
cpu_temps = [45, 82, 60, 91, 55, 88, 70]
overheat_list = []   # List ว่างไว้เก็บค่าที่ร้อนเกิน

for i, temp in enumerate(cpu_temps, start=1):
    if temp >= 80:
        print(f"[แจ้งเตือน] เครื่องที่ {i} ร้อนเกินเกณฑ์! ({temp} °C)")
        overheat_list.append(temp)
    else:
        print(f"[ปกติ] เครื่องที่ {i}: {temp} °C")

print("-" * 40)
print("จำนวนเครื่องที่ร้อนเกิน 80 °C:", len(overheat_list), "เครื่อง")
print("อุณหภูมิที่พบปัญหา:", overheat_list)
```

### ตัวอย่างที่ 2: โปรแกรมคำนวณคะแนนสอบและหาค่าเฉลี่ยด้วย `for` loop

```python
scores = [75, 88, 62, 95, 50, 80]

total = 0
passed = 0

for s in scores:
    total += s
    if s >= 60:
        passed += 1

average = total / len(scores)

print(f"คะแนนทั้งหมด: {scores}")
print(f"คะแนนรวม: {total} | ค่าเฉลี่ย: {average:.2f}")
print(f"จำนวนคนที่สอบผ่าน (>= 60): {passed} คน จาก {len(scores)} คน")
```

### ตัวอย่างที่ 3 (เสริม): Array 2 มิติ (`List` ซ้อน `List`) กับ Nested Loop

เมื่อต้องเก็บข้อมูลแบบตาราง (มีแถวและคอลัมน์) เช่น รายการสินค้าพร้อมราคา สามารถนำ List มาซ้อนใน List ได้:

```python
# ตารางสินค้า: [ชื่อสินค้า, ราคา]
inventory = [
    ["เมาส์ไร้สาย", 350],
    ["คีย์บอร์ดเกมมิ่ง", 890],
    ["แผ่นรองเมาส์", 120]
]

print("รายการสินค้าในคลัง:")
for row in inventory:
    name = row[0]
    price = row[1]
    print(f"- {name} : {price} บาท")
```

## สรุปสาระสำคัญประจำบท (Cheat Sheet)

1. **`List` (`[...]`)** คือ Dynamic Array ของ Python ที่เก็บข้อมูลเป็นชุด ขยายขนาดได้เอง และเก็บคละชนิดได้
2. **Index** นับจากซ้ายเริ่มที่ **`0`** เสมอ และนับจากขวาเริ่มที่ **`-1`** (`list[-1]` คือตัวสุดท้าย)
3. **การจัดการสมาชิก:**
   - เพิ่มต่อท้าย: `.append(x)` | แทรกตามตำแหน่ง: `.insert(i, x)`
   - ลบตามชื่อ: `.remove(x)` | ลบตามตำแหน่ง: `.pop(i)`
   - นับจำนวน: `len(list)` | เช็กว่ามีไหม: `if x in list:`
4. **การใช้คู่กับ Loop:**
   - อ่านค่าทีละตัว: `for x in my_list:`
   - แก้ไขค่า/ใช้ตำแหน่ง: `for i in range(len(my_list)):`
   - ได้ทั้งลำดับและค่า: `for i, x in enumerate(my_list):`
   - รับค่าไม่รู้จำนวนรอบมาเก็บ: ใช้ `while True:` คู่กับ `.append()`
