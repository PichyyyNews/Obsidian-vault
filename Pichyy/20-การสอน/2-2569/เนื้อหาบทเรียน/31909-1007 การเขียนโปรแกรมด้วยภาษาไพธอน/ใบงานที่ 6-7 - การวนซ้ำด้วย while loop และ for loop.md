## ข้อที่ 1: โปรแกรมตารางสูตรคูณและตัวกรองเลขคู่ (`for` loop + `range` + `continue`) [6 คะแนน]

### โจทย์
ให้นักศึกษาเขียนโปรแกรมรับแม่สูตรคูณ 1 ค่าจากผู้ใช้ (`input`) แล้วแสดงผลตารางสูตรคูณตั้งแต่คูณ 1 ถึง 12 โดยใช้ **`for` loop** ร่วมกับ **`range()`**

**เงื่อนไขเพิ่มเติม:**
1. แสดงหัวข้อ `--- ตารางสูตรคูณแม่ [เลขที่กรอก] ---`
2. ให้ใช้คำสั่ง **`continue`** เพื่อ **ข้ามผลคูณที่ตัวคูณเป็นเลขหาร 5 ลงตัว** (เช่น ข้าม `x 5` และ `x 10` ไม่ต้องแสดงผล)
3. ให้นักศึกษาวาด **Flowchart** ของข้อนี้ลงในกระดาษคำตอบด้วย

### ตัวอย่างผลลัพธ์ (กรอกเลข `2`)
```text
ป้อนแม่สูตรคูณที่ต้องการ: 2
--- ตารางสูตรคูณแม่ 2 ---
2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
2 x 4 = 8
2 x 6 = 12
2 x 7 = 14
2 x 8 = 16
2 x 9 = 18
2 x 11 = 22
2 x 12 = 24
```

## ข้อที่ 2: ระบบทดสอบป้อนรหัสผ่านและปลดล็อกเครื่องช่าง (`while` loop + `break` + `while-else`) [7 คะแนน]

### โจทย์
ให้นักศึกษาเขียนโปรแกรมจำลองการล็อกอินเข้าใช้งานโปรแกรมตรวจซ่อมคอมพิวเตอร์ โดยใช้ **`while` loop** กำหนดรหัสผ่านที่ถูกต้องคือ `"tech2026"`

**เงื่อนไขการทำงาน:**
1. ผู้ใช้มีสิทธิ์กรอกรหัสผ่านได้ **สูงสุด 3 ครั้ง**
2. หากกรอกถูกต้อง:
   - แสดงข้อความ `"เข้าสู่ระบบสำเร็จ! ยินดีต้อนรับช่างเทคนิค"`
   - ใช้คำสั่ง **`break`** เพื่อออกจากลูปทันที
3. หากกรอกผิด:
   - แสดงข้อความ `"รหัสผ่านไม่ถูกต้อง (เหลือโอกาสอีก X ครั้ง)"`
4. หากกรอกผิดครบ 3 ครั้ง (ลูปจบรอบโดยไม่เจอ `break`):
   - ใช้บล็อก **`else:`** หลัง `while` เพื่อแสดงข้อความ `"คุณกรอกรหัสผิดครบ 3 ครั้ง ระบบถูกล็อก!"`

### ตัวอย่างผลลัพธ์ (กรณีกรอกผิดครบ 3 ครั้ง)
```text
กรุณากรอกรหัสผ่าน (ครั้งที่ 1/3): 1111
รหัสผ่านไม่ถูกต้อง (เหลือโอกาสอีก 2 ครั้ง)
กรุณากรอกรหัสผ่าน (ครั้งที่ 2/3): 2222
รหัสผ่านไม่ถูกต้อง (เหลือโอกาสอีก 1 ครั้ง)
กรุณากรอกรหัสผ่าน (ครั้งที่ 3/3): 3333
รหัสผ่านไม่ถูกต้อง (เหลือโอกาสอีก 0 ครั้ง)
คุณกรอกรหัสผิดครบ 3 ครั้ง ระบบถูกล็อก!
```

## ข้อที่ 3: เครื่องคิดเงินค่าซ่อมบำรุงคอมพิวเตอร์อัตโนมัติ (`while True:` + Accumulator + `break`) [7 คะแนน]

### โจทย์
ให้นักศึกษาเขียนโปรแกรมรับราคาค่าอะไหล่/ค่าซ่อมหลายรายการต่อเนื่อง เพื่อรวมยอดบิลให้ลูกค้า โดยไม่ทราบจำนวนชิ้นล่วงหน้า

**เงื่อนไขการทำงาน:**
1. ใช้ลูป **`while True:`** รับค่าราคาสินค้าเป็นจำนวนเต็มทีละรายการ (`input`)
2. หากผู้ใช้กรอกเลข **`0`**: ให้หยุดรับรายการด้วย **`break`** แล้วสรุปยอดรวมทั้งหมด
3. หากผู้ใช้กรอก **เลขติดลบ** (เช่น `-50`): ให้แจ้งเตือน `"ราคาห้ามติดลบ! กรุณากรอกใหม่"` แล้วใช้ **`continue`** ข้ามไปรับค่ารอบถัดไป (ห้ามนำเลขติดลบมาบวกสะสม)
4. เมื่อจบการรับข้อมูล ให้แสดง:
   - จำนวนรายการสินค้าที่ถูกต้องทั้งหมด (ไม่นับเลข 0 และเลขติดลบ)
   - ยอดรวมค่าใช้จ่ายทั้งหมด (บาท)

### ตัวอย่างผลลัพธ์
```text
=== ระบบคิดเงินค่าซ่อมคอมพิวเตอร์ ===
กรอกราคาสินค้า (พิมพ์ 0 เพื่อคิดเงิน): 500
กรอกราคาสินค้า (พิมพ์ 0 เพื่อคิดเงิน): -100
ราคาห้ามติดลบ! กรุณากรอกใหม่
กรอกราคาสินค้า (พิมพ์ 0 เพื่อคิดเงิน): 1200
กรอกราคาสินค้า (พิมพ์ 0 เพื่อคิดเงิน): 350
กรอกราคาสินค้า (พิมพ์ 0 เพื่อคิดเงิน): 0
---------------------------------------
จำนวนรายการทั้งหมด: 3 รายการ
ยอดรวมสุทธิ: 2050 บาท
```
