## 3. ขั้นที่ 1 — ฟังก์ชัน (Functions)

### 3.1 ฟังก์ชันคืออะไร

ฟังก์ชัน = **ชุดคำสั่งที่ตั้งชื่อไว้** แล้วเรียกใช้ซ้ำได้หลายครั้ง
เหมือนปุ่มลัด: เขียนครั้งเดียว ใช้ได้ตลอด

### 3.2 รูปแบบ

```lua
local function ชื่อฟังก์ชัน()
    -- คำสั่งข้างใน
end
```

### 3.3 ฟังก์ชันแรก

```lua
local function sayHello()
    print("สวัสดีจากฟังก์ชัน")
end

sayHello()
sayHello()
```

**ผลลัพธ์**

```text
สวัสดีจากฟังก์ชัน
สวัสดีจากฟังก์ชัน
```

> [!note] เขียนครั้งเดียว เรียกกี่ครั้งก็ได้
> ถ้าแก้ข้อความในฟังก์ชัน เปลี่ยนทีเดียวทุกจุดที่เรียก

> [!note] ประกาศกับเรียก ต่างกัน
> | บรรทัด | คืออะไร | เกิดขึ้นเมื่อไหร่ |
> | :--- | :--- | :--- |
> | `local function sayHello()` | **ประกาศ** ฟังก์ชัน (ยังไม่ทำงาน) | ตอนโหลดสคริปต์ |
> | `sayHello()` | **เรียกใช้** (ทำงานจริง) | ตอนรันถึงบรรทัดนั้น |
>
> ถ้าประกาศแล้วไม่เรียก จะไม่มีอะไรเกิดขึ้น
> และถ้าเรียกก่อนบรรทัดประกาศ จะได้ `attempt to call a nil value`

### 3.4 ส่งค่าเข้า (พารามิเตอร์)

```lua
local function greet(name)
    print("สวัสดี " .. name)
end

greet("นัท")
greet("มิ้น")
```

**ผลลัพธ์**

```text
สวัสดี นัท
สวัสดี มิ้น
```

### 3.5 ส่งค่าออก (`return`)

```lua
local function add(a, b)
    return a + b
end

local result = add(3, 5)
print("ผลบวก: " .. result)
```

**ผลลัพธ์:** `ผลบวก: 8`

| คำศัพท์ | ความหมาย |
| :--- | :--- |
| พารามิเตอร์ (`a`, `b`) | ค่าที่ส่งเข้าไปในวงเล็บ |
| `return` | ค่าที่ส่งกลับออกมา |
| เรียกใช้ | `add(3, 5)` |

> [!warning] `return` ต้องอยู่ท้ายฟังก์ชัน
> เมื่อเจอ `return` ฟังก์ชันจะจบทันที คำสั่งที่อยู่หลัง `return` จะไม่ทำงาน

> [!note] `return` ต่างจาก `print` อย่างไร
> * `print` แค่ **แสดงผล** — เอาค่าไปใช้ต่อไม่ได้
> * `return` **ส่งค่ากลับ** — เอาไปเก็บในตัวแปรหรือคำนวณต่อได้
>
> `local result = add(3, 5)` จึงได้ 8 มาเก็บไว้
> ถ้าเปลี่ยน `return a + b` เป็น `print(a + b)` จะเห็นเลข 8 แต่ `result` จะเป็น `nil`

## 5. ขั้นที่ 3 — `while` loop

### 5.1 รูปแบบ

```lua
while เงื่อนไข do
    -- ทำซ้ำตราบใดที่เงื่อนไขยังจริง
end
```

### 5.2 ตัวอย่าง: นับ 1 ถึง 5

```lua
local count = 1

while count <= 5 do
    print("รอบที่ " .. count)
    count = count + 1
end

print("จบแล้ว")
```

**ผลลัพธ์**

```text
รอบที่ 1
รอบที่ 2
รอบที่ 3
รอบที่ 4
รอบที่ 5
จบแล้ว
```

> [!danger] ลืมเพิ่มค่า = เกมค้าง
> ถ้าไม่มี `count = count + 1` เงื่อนไขจะเป็นจริงตลอด → **infinite loop** เกมค้าง ต้องปิด Studio
> กฎ: ทุกลูป `while` ต้องมีทางออก

> [!note] ทำไมต้องมี `count = count + 1`
> ถ้าไม่มีค่านี้ `count` จะเป็น 1 ตลอด → `count <= 5` จริงตลอด → วนไม่หยุด (เกมค้าง)
> ทุกลูป `while` จึงต้องมี **คำสั่งที่ทำให้เงื่อนไขเปลี่ยน** อยู่ข้างในเสมอ

### 5.3 `while` กับ `for` ต่างกันอย่างไร

| ลูป | ใช้เมื่อ |
| :--- | :--- |
| `for i = 1, 5` | รู้จำนวนรอบแน่นอน |
| `while` | ไม่รู้จำนวนรอบ รู้แค่เงื่อนไขหยุด |

## 6. ขั้นที่ 4 — `repeat ... until`

### 6.1 รูปแบบ

```lua
repeat
    -- ทำก่อน 1 ครั้ง
until เงื่อนไข
```

### 6.2 ตัวอย่าง

```lua
local count = 1

repeat
    print("ทำงานรอบ " .. count)
    count = count + 1
until count > 3
```

**ผลลัพธ์**

```text
ทำงานรอบ 1
ทำงานรอบ 2
ทำงานรอบ 3
```

> [!note] ต่างจาก `while` ตรงไหน
> `repeat` **ทำก่อนแล้วค่อยตรวจ** จึงทำงานอย่างน้อย 1 ครั้งเสมอ
> `while` ตรวจก่อน ถ้าเงื่อนไขเท็จตั้งแต่แรกจะไม่ทำเลย

## 7. ขั้นที่ 5 — `task.wait()` หน่วงเวลา

### 7.1 ทำไมต้องรอ

ถ้าไม่หน่วงเวลา ลูปจะทำงานเร็วมากจนมองไม่เห็นการเปลี่ยนแปลง

```lua
for i = 1, 3 do
    print("ครั้งที่ " .. i)
    task.wait(1)
end
```

> [!warning] ห้ามใช้ `wait()`
> `wait()` เป็นคำสั่งเก่าที่เลิกใช้แล้ว ให้ใช้ **`task.wait(วินาที)`** แทนเสมอ

### 7.2 หน่วงในลูป `while`

```lua
local count = 0

while count < 3 do
    count = count + 1
    print("นับ " .. count)
    task.wait(2)
end
```

**ผลลัพธ์:** พิมพ์ทุก 2 วินาที จำนวน 3 ครั้ง

> [!note] เลือกใช้ลูปแบบไหน
> | สถานการณ์ | ใช้ |
> | :--- | :--- |
> | รู้จำนวนรอบ เช่น สร้าง 5 ขั้น | `for` |
> | ไม่รู้จำนวนรอบ แต่รู้เงื่อนไขหยุด | `while` |
> | ต้องทำอย่างน้อย 1 ครั้งก่อนตรวจ | `repeat ... until` |
>
> ทั้งสามแบบใช้ `task.wait()` หน่วงเวลาได้เหมือนกัน

## 8. ขั้นที่ 6 — ตาราง (Tables)

### 8.1 table คือกล่องหลายช่อง

```lua
local colors = {
    Color3.fromRGB(220, 30, 30),
    Color3.fromRGB(255, 220, 0),
    Color3.fromRGB(0, 200, 80),
}

print(#colors)        -- 3 (จำนวนสมาชิก)
print(colors[1])      -- สีแรก (แดง)
print(colors[3])      -- สีที่สาม (เขียว)
```

> [!important] index เริ่มที่ 1
> ต่างจากภาษาอื่นที่เริ่ม 0 — Lua เริ่มที่ **1**
> `colors[0]` จะได้ `nil`

### 8.2 วนอ่านด้วย `ipairs`

```lua
for i, color in ipairs(colors) do
    print("สีที่ " .. i)
end
```

**ผลลัพธ์**

```text
สีที่ 1
สีที่ 2
สีที่ 3
```

### 8.3 เพิ่มค่าเข้าตาราง

```lua
local names = {"นัท", "มิ้น"}
table.insert(names, "ปอ")
print(#names)          -- 3
print(names[3])        -- ปอ
```

> [!tip] table ใช้ทำอะไรในเกม
> เก็บรายชื่อผู้เล่น · เก็บไอเทมในกระเป๋า · เก็บลำดับด่าน · เก็บสีของไฟจราจร

## 9. ขั้นที่ 7 — มินิโปรเจกต์: ไฟจราจร

### 9.1 เตรียมฉาก

1. สร้าง Part 3 ชิ้น ตั้งชื่อ `RedLight`, `YellowLight`, `GreenLight`
2. วางเรียง vertically ห่างกัน 4 studs
3. ติ๊ก **Anchored** ทั้ง 3 ชิ้น

### 9.2 เขียนฟังก์ชัน + ลูป

```lua
-- TrafficLightScript
local red = workspace.RedLight
local yellow = workspace.YellowLight
local green = workspace.GreenLight

local RED = Color3.fromRGB(220, 30, 30)
local YELLOW = Color3.fromRGB(255, 220, 0)
local GREEN = Color3.fromRGB(0, 200, 80)
local OFF = Color3.fromRGB(50, 50, 50)

local function setLight(part, color, isOn)
    if isOn then
        part.Color = color
        part.Material = Enum.Material.Neon
    else
        part.Color = OFF
        part.Material = Enum.Material.SmoothPlastic
    end
end

while true do
    setLight(red, RED, true)
    setLight(yellow, YELLOW, false)
    setLight(green, GREEN, false)
    task.wait(3)

    setLight(red, RED, false)
    setLight(yellow, YELLOW, true)
    setLight(green, GREEN, false)
    task.wait(1)

    setLight(red, RED, false)
    setLight(yellow, YELLOW, false)
    setLight(green, GREEN, true)
    task.wait(3)
end
```

### 9.3 ผลที่ควรเห็น

| เวลา | ไฟที่ติด |
| :--- | :--- |
| 0–3 วินาที | แดง |
| 3–4 วินาที | เหลือง |
| 4–7 วินาที | เขียว |
| 7 วินาที | กลับไปแดง วนซ้ำ |

> [!danger] ถ้าเกมค้างทันทีที่กด Play
> มักเกิดจาก `while true do` ที่ **ไม่มี `task.wait()`** ข้างใน
> ต้องมี `task.wait()` ทุกครั้งในลูป Forever

### 9.4 ปรับให้สวยขึ้น (ทำก็ได้ ไม่ทำก็ได้)

```lua
-- เพิ่มเอฟเฟกต์เสียงตอนไฟเปลี่ยน (ถ้ามี Sound ใน Workspace)
-- local sound = workspace.TrafficSound
-- sound:Play()
```

> [!note] อ่านโค้ดไฟจราจรให้เป็น
> * `setLight(part, color, isOn)` — ฟังก์ชันเดียวใช้ได้ทั้ง 3 ดวง เพราะส่ง Part เข้าไป
> * `while true do` — วนตลอดไปจนกว่าจะหยุดเกม
> * `task.wait(3)` — ค้าง 3 วินาทีก่อนไปบรรทัดถัดไป
> * ลำดับในลูป = แดง 3 วิ → เหลือง 1 วิ → เขียว 3 วิ → กลับไปเริ่มใหม่
>
> ถ้าลบ `task.wait` ออก ไฟจะเปลี่ยนรัวจนมองไม่เห็น และเกมอาจค้าง

## 10. ขั้นที่ 8 — หาบั๊กด้วย `print`

### 10.1 วิธีไล่ค่า

```lua
local score = 45

print("ค่าคะแนน = " .. score)   -- ดูค่าจริงก่อนตัดสิน

if score >= 50 then
    print("ผ่าน")
else
    print("ไม่ผ่าน")
end
```

> [!tip] กฎการหาบั๊ก
> 1. `print` ค่าที่สงสัยก่อน `if`
> 2. ถ้าค่าไม่ตรงที่คิด → ปัญหาอยู่ก่อนหน้า
> 3. ถ้าค่าถูกแต่ผลผิด → ปัญหาอยู่ที่เงื่อนไข

### 10.2 อ่าน Error ใน Output

| อาการ | ความหมาย |
| :--- | :--- |
| บรรทัดแรกสีแดง | จุดที่พังจริง |
| `XxxScript:12:` | ไฟล์และบรรทัดที่ผิด |
| บรรทัดถัด ๆ ไป | เส้นทางการเรียก (ไม่ต้องอ่านละเอียด) |

## 11. Error ที่พบบ่อยในสัปดาห์นี้

| ข้อความใน Output | สาเหตุ | วิธีแก้ |
| :--- | :--- | :--- |
| เกมค้างทันที | `while true` ไม่มี `task.wait` | เติม `task.wait(1)` |
| `attempt to call a nil value` | เรียกชื่อฟังก์ชันผิด | ตรวจชื่อให้ตรง |
| `'end' expected` | ลืม `end` ปิดฟังก์ชัน/ลูป | เติมให้ครบ |
| `attempt to index a nil value` | เข้าถึง table ช่องที่ไม่มี | ตรวจ index เริ่มที่ 1 |
| `bad argument #1 to 'insert'` | `table.insert` ใช้ผิดรูป | `table.insert(t, ค่า)` |
| `RedLight is not a valid member` | ชื่อ Part ไม่ตรง | ตรวจตัวพิมพ์ |

## 14. คำถามทบทวนท้ายคาบ

1. ฟังก์ชันช่วยอะไร ทำไมไม่เขียนโค้ดซ้ำ ๆ
2. พารามิเตอร์กับ `return` ต่างกันอย่างไร
3. `while` กับ `repeat` ต่างกันตรงไหน
4. ทำไมต้องมี `task.wait()` ในลูป `while true`
5. table ใน Lua เริ่มนับ index ที่เท่าไร
6. `#colors` หมายถึงอะไร

> [!success]- เฉลย (คลิกเพื่อเปิด)
> 1. ช่วยให้เขียนครั้งเดียวใช้ซ้ำ แก้ที่เดียวทุกจุดเปลี่ยน
> 2. พารามิเตอร์ = ค่าส่งเข้า · `return` = ค่าส่งออก
> 3. `repeat` ทำก่อนตรวจ (ทำอย่างน้อย 1 ครั้ง) · `while` ตรวจก่อนทำ
> 4. ไม่งั้นลูปจะวนเร็วมากจนเกมค้าง
> 5. เริ่มที่ 1
> 6. จำนวนสมาชิกในตาราง
