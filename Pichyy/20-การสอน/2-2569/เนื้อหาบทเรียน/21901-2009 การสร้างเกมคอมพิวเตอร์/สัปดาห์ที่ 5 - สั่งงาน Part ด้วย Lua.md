## 2.5 หลักการที่ต้องเข้าใจก่อนเขียน Script

> [!important] อ่านส่วนนี้ก่อน — เป็นรากฐานของทุกบทเรียน Lua ที่เหลือ
> ถ้าเข้าใจ 4 เรื่องนี้ การเขียน script ทุกอย่างในบทต่อไปจะง่ายขึ้นมาก

---

### 2.5.1 Roblox Studio มองทุกอย่างเป็น "Object"

ใน Roblox Studio ทุกสิ่งที่เห็นในเกม ไม่ว่าจะเป็นก้อนหิน พื้น กำแพง หรือตัวละคร — ล้วนเป็น **Object (วัตถุ)** ที่โปรแกรมสร้างขึ้น

Object แต่ละชิ้นมี 2 สิ่งที่สำคัญ:
1. **Properties (คุณสมบัติ)** — ข้อมูลที่บอกว่า Object นี้มีลักษณะอย่างไร เช่น มีสีอะไร ขนาดเท่าไหร่ อยู่ตรงไหน
2. **Methods (คำสั่ง)** — สิ่งที่สั่งให้ Object ทำได้ เช่น ทำลายตัวเอง เปลี่ยนสี (เรียนในบทต่อไป)

> [!example] ตัวอย่างในชีวิตจริง
> สมมติว่า `รถยนต์` คือ Object หนึ่ง
> - **Properties:** สี = แดง, ยี่ห้อ = Toyota, ความเร็วปัจจุบัน = 60 กม./ชม.
> - **Methods:** เร่งเครื่อง(), เบรก(), เปิดประตู()
>
> `Part` ใน Roblox ก็เหมือนกัน — มี Properties เช่น Color, Size, Position และ Methods เช่น Destroy()

---

### 2.5.2 จุด `.` คืออะไร — ทำไมต้องมีจุด

เมื่อเขียน Lua เราใช้ **จุด `.`** เพื่อบอกว่า "เข้าถึงสิ่งที่อยู่ใน Object นั้น"

```
Object.สิ่งที่อยู่ข้างใน
```

**ตัวอย่าง:**

```lua
workspace.PaintPart          -- เข้าถึง Object ชื่อ PaintPart ที่อยู่ใน workspace
workspace.PaintPart.Color    -- เข้าถึง Property ชื่อ Color ของ PaintPart
workspace.PaintPart.Size     -- เข้าถึง Property ชื่อ Size ของ PaintPart
```

ให้นึกภาพแบบนี้:

```
workspace
   └── PaintPart          ← Object (ก้อนบล็อก)
         ├── Color        ← Property (สี)
         ├── Size         ← Property (ขนาด)
         ├── Position     ← Property (ตำแหน่ง)
         └── Anchored     ← Property (ล็อกอยู่กับที่ไหม)
```

> [!note] จุด `.` = "ของ" หรือ "ภายใน"
> `workspace.PaintPart.Color` อ่านว่า **"Color ของ PaintPart ที่อยู่ใน workspace"**
> เหมือนบอกทิศทางที่อยู่จากนอกสุดเข้าไปข้างใน

---

### 2.5.3 Property คืออะไร — มีอะไรบ้างใน Part

**Property** คือคุณสมบัติที่บรรยายลักษณะของ Object นั้น ๆ เราอ่านค่าได้ และเปลี่ยนค่าได้ด้วยโค้ด

Properties ของ **Part** ที่จะใช้ในบทนี้:

| Property       | ความหมาย                    | ชนิดข้อมูล | ตัวอย่างค่า                 |
| :------------- | :-------------------------- | :--------- | :-------------------------- |
| `Color`        | สีของบล็อก                  | Color3     | `Color3.fromRGB(255, 0, 0)` |
| `Size`         | ขนาด กว้าง × สูง × ยาว      | Vector3    | `Vector3.new(4, 1, 4)`      |
| `Position`     | ตำแหน่ง X, Y, Z ในโลก       | Vector3    | `Vector3.new(0, 5, 0)`      |
| `Anchored`     | ล็อกไม่ให้ตก (จริง/เท็จ)    | boolean    | `true` หรือ `false`         |
| `Transparency` | ความโปร่งใส 0=ทึบ 1=ล่องหน  | number     | `0.5`                       |
| `Material`     | วัสดุผิว เช่น หิน โลหะ      | Enum       | `Enum.Material.Neon`        |
| `Name`         | ชื่อของ Object              | string     | `"PaintPart"`               |
| `Parent`       | Object แม่ที่ซ้อนอยู่ข้างใน | Instance   | `workspace`                 |

> [!tip] ดู Property ทั้งหมดได้ที่ไหน
> เลือก Part ใน Studio แล้วดูแถบ **Properties** ด้านขวา — ทุก Property ที่เห็นในแถบนั้น เราเปลี่ยนได้ด้วยโค้ด Lua ทั้งหมด

---

### 2.5.4 การ "อ่านค่า" vs "เขียนค่า" Property

> [!warning] ข้อผิดพลาดที่พบบ่อย — ต้องกำหนด `part` ก่อนเสมอ
> โค้ดทุกบรรทัดในส่วนนี้ **ใช้งานไม่ได้ถ้าเขียนอยู่เดี่ยว ๆ**
> ต้องมีบรรทัด `local part = workspace.PaintPart` อยู่ก่อนเสมอ
> ถ้าไม่มี — `part` จะเป็น `nil` และจะ error ว่า `attempt to index nil with 'Color'`

**โค้ดที่ถูกต้อง — ต้องครบทุกบรรทัดเสมอ:**

**อ่านค่า** (ดูว่า Property มีค่าอะไรอยู่):
```lua
-- บรรทัดนี้ต้องมีก่อนเสมอ!
local part = workspace.PaintPart

-- จากนั้นจึงอ่าน Property ได้
local currentColor = part.Color    -- เก็บค่าสีปัจจุบันไว้ในตัวแปร
print(part.Size)                   -- พิมพ์ขนาดออก Output
print(part.Name)                   -- พิมพ์ชื่อออก Output
```

**เขียนค่า** (เปลี่ยน Property ให้เป็นค่าใหม่):
```lua
-- บรรทัดนี้ต้องมีก่อนเสมอ!
local part = workspace.PaintPart

-- จากนั้นจึงเปลี่ยน Property ได้
part.Color = Color3.fromRGB(255, 0, 0)   -- เปลี่ยนสีเป็นแดง
part.Size = Vector3.new(10, 1, 10)       -- เปลี่ยนขนาดเป็น 10×1×10
part.Anchored = true                     -- ล็อกให้ติดอยู่กับที่
```

> [!note] สังเกตเครื่องหมาย `=`
> ในบทที่ 4 เรียนว่า `=` คือ **การกำหนดค่า** ไม่ใช่การเปรียบเทียบ
> `part.Color = ...` แปลว่า "ให้ Color ของ part มีค่าเป็น ..."
> ไม่ใช่การถามว่า "Color เท่ากับ ... ไหม" (อันนั้นใช้ `==`)

> [!caution] ทำไม `attempt to index nil with 'Color'` ถึงเกิด
> error นี้แปลว่า Lua พยายามเข้าถึง `.Color` ของ `part` แต่ `part` เป็น **nil** (ว่างเปล่า ไม่มีค่า)
> สาเหตุที่ `part` เป็น nil มี 2 กรณี:
> 1. **ลืมเขียน** `local part = workspace.PaintPart` → แก้โดยเพิ่มบรรทัดนี้ก่อน
> 2. **ชื่อ Part ผิด** เช่น เขียน `workspace.paintpart` แต่ใน Studio ชื่อ `PaintPart` → ตรวจชื่อให้ตรง (ตัวใหญ่-เล็กสำคัญ)

### 2.5.5 ชนิดข้อมูลพิเศษที่ต้องรู้จัก

Properties บางตัวไม่ใช่ตัวเลขธรรมดา แต่เป็นข้อมูลชนิดพิเศษที่ต้องสร้างด้วยคำสั่งเฉพาะ:

**Color3 — ข้อมูลสี**

สีใน Roblox ไม่ใช่แค่ชื่อ "แดง" หรือ "น้ำเงิน" แต่เป็นการผสมแสงสามสี: **Red (แดง) + Green (เขียว) + Blue (น้ำเงิน)** แต่ละสีมีค่า 0 ถึง 255

```lua
-- Color3.fromRGB(แดง, เขียว, น้ำเงิน)
part.Color = Color3.fromRGB(255, 0, 0)     -- แดงล้วน
part.Color = Color3.fromRGB(0, 0, 255)     -- น้ำเงินล้วน
part.Color = Color3.fromRGB(255, 255, 0)   -- เหลือง (แดง+เขียว)
part.Color = Color3.fromRGB(0, 0, 0)       -- ดำ (ไม่มีแสงเลย)
part.Color = Color3.fromRGB(255, 255, 255) -- ขาว (แสงเต็มทุกสี)
```

> [!tip] จำง่าย ๆ
> RGB = ไฟสีในจอโทรทัศน์และจอมือถือ ผสมกันได้ทุกสี
> ค่า 0 = ไม่มีสีนั้นเลย · ค่า 255 = สีนั้นเข้มเต็มที่

**Vector3 — ข้อมูลตำแหน่งและขนาด (3 มิติ)**

ในโลก 3D ทุกอย่างต้องระบุ 3 ค่า: X (กว้าง/ซ้าย-ขวา), Y (สูง/ขึ้น-ลง), Z (ลึก/หน้า-หลัง)

```lua
-- Vector3.new(X, Y, Z)
part.Position = Vector3.new(0, 5, 0)      -- กลางโลก สูง 5 studs
part.Position = Vector3.new(10, 0, -5)   -- ขยับขวา 10 หน้า 5
part.Size = Vector3.new(4, 1, 4)         -- กว้าง 4 สูง 1 ยาว 4
```

> [!note] Y คือความสูง
> ใน Roblox ถ้า Y = 0 คือพื้น ยิ่ง Y มากยิ่งสูงขึ้น

## 3. ขั้นที่ 1 — เตรียม Part ให้พร้อม

### 3.1 สร้าง Part

1. ใน Explorer คลิกที่ **Workspace**
2. กด **+** (Insert Object) → เลือก **Part**
3. ตั้งชื่อใน Properties → **Name** = `PaintPart`
4. ติ๊ก **Anchored** = ✅
5. ยก Part ขึ้นเหนือพื้นเล็กน้อย (กด **E** แล้วลากลูกศรขึ้น)

> [!warning] ชื่อต้องตรงเป๊ะ
> `PaintPart` ไม่เท่ากับ `paintpart` และไม่เท่ากับ `Paint Part`
> ถ้าชื่อไม่ตรง จะได้ error `PaintPart is not a valid member of Workspace`

### 3.2 ตรวจว่า Part อยู่ที่ไหน

| ตำแหน่ง                  | เขียนในโค้ด                |
| :----------------------- | :------------------------- |
| อยู่ใน Workspace (บนสุด) | `workspace.PaintPart`      |
| อยู่ใน Model ชื่อ `Shop` | `workspace.Shop.PaintPart` |
| อยู่ใน Part อีกชิ้น      | `workspace.Box.PaintPart`  |

> [!note] `workspace` คือทางลัด
> `workspace.PaintPart` เขียนแทน `game.Workspace.PaintPart` ได้เลย
> ทั้งสองแบบทำงานเหมือนกัน

## 4. ขั้นที่ 2 — เปลี่ยนสี

### 4.1 สร้างสคริปต์

1. คลิกขวา **ServerScriptService** → **Insert Object** → **Script**
2. ตั้งชื่อ `ColorScript`

```lua
-- ColorScript
local part = workspace.PaintPart

part.Color = Color3.fromRGB(255, 80, 0)
print("เปลี่ยนสีเรียบร้อย")
```

3. กด **Play (F5)** → ดูที่ Part
4. กด **Stop**

**ผลลัพธ์:** Part เปลี่ยนเป็นสีส้ม และ Output ขึ้น `เปลี่ยนสีเรียบร้อย`

> [!note] อธิบายทีละบรรทัด
> | บรรทัด | ทำอะไร | ถ้าผิด |
> | :--- | :--- | :--- |
> | `local part = workspace.PaintPart` | หยิบ Part มาเก็บในตัวแปร | ชื่อผิด → `not a valid member` |
> | `part.Color = ...` | สั่งเปลี่ยนสี | เขียน `part.Colour` → ได้ `nil` |
> | `Color3.fromRGB(255, 80, 0)` | สร้างค่าสีจาก RGB | ใส่ `(255, 80)` → `missing argument` |
>
> `part` เป็นเพียง **ชื่อที่เราตั้งเอง** ไม่ใช่คำสั่งของ Lua — จะใช้ `กล่อง` หรือ `x` ก็ได้

### 4.2 RGB คืออะไร

`Color3.fromRGB(แดง, เขียว, น้ำเงิน)` โดยแต่ละค่าอยู่ที่ **0–255**

| สี     | RGB             |
| :----- | :-------------- |
| แดง    | `255, 0, 0`     |
| ส้ม    | `255, 80, 0`    |
| เหลือง | `255, 220, 0`   |
| เขียว  | `0, 200, 80`    |
| ฟ้า    | `0, 170, 255`   |
| ม่วง   | `150, 60, 255`  |
| ขาว    | `255, 255, 255` |
| ดำ     | `0, 0, 0`       |

> [!tip] อยากได้สีอื่น
> เปิด **Properties → Color** ใน Studio แล้วจดค่าตัวเลขมาใช้
> หรือใช้ `Color3.fromHSV(h, s, v)` ก็ได้ (จะเรียนทีหลัง)

## 5. ขั้นที่ 3 — เปลี่ยนวัสดุ ขนาด และความโปร่งใส

### 5.1 ตาราง Property ที่ต้องรู้

| Property       | ค่าที่ใส่                 | ความหมาย         |
| :------------- | :------------------------ | :--------------- |
| `Color`        | `Color3.fromRGB(r, g, b)` | สีของชิ้นส่วน    |
| `Material`     | `Enum.Material.Neon`      | เนื้อวัสดุ       |
| `Size`         | `Vector3.new(x, y, z)`    | ขนาด (studs)     |
| `Transparency` | `0` ถึง `1`               | ความโปร่งใส      |
| `Anchored`     | `true` / `false`          | ล็อกไม่ให้ร่วง   |
| `CanCollide`   | `true` / `false`          | ชนได้หรือทะลุได้ |

### 5.2 วัสดุที่ใช้บ่อย

| วัสดุ    | เขียนว่า                      | ลักษณะ      |
| :------- | :---------------------------- | :---------- |
| พลาสติก  | `Enum.Material.Plastic`       | มาตรฐาน     |
| เรียบมัน | `Enum.Material.SmoothPlastic` | เงาเล็กน้อย |
| เรืองแสง | `Enum.Material.Neon`          | สว่างเรือง  |
| กระจก    | `Enum.Material.Glass`         | โปร่งใส     |
| ไม้      | `Enum.Material.Wood`          | ผิวไม้      |
| โลหะ     | `Enum.Material.Metal`         | ผิวโลหะ     |
| น้ำ      | `Enum.Material.Water`         | ผิวน้ำ      |

### 5.3 โค้ดรวม

```lua
-- PaintScript
local part = workspace.PaintPart

part.Color = Color3.fromRGB(0, 170, 255)
part.Material = Enum.Material.Neon
part.Size = Vector3.new(8, 1, 8)
part.Transparency = 0.2

print("ปรับแต่ง PaintPart เสร็จ")
```

> [!danger] ทำไม Stop แล้วสีกลับเป็นเหมือนเดิม
> เพราะโค้ดแก้ค่าเฉพาะตอน **เกมกำลังรัน**
> พอ Stop เกมจะคืนค่าที่บันทึกไว้ — เป็นเรื่องปกติ ไม่ใช่บั๊ก

> [!note] อ่านโค้ด 4 บรรทัดให้เป็น
> 1. `part.Color` — ต้องใช้ค่าจาก `Color3`
> 2. `part.Material` — ต้องใช้ `Enum.Material.ชื่อวัสดุ`
> 3. `part.Size` — ต้องใช้ `Vector3.new(x, y, z)`
> 4. `part.Transparency` — ตัวเลข 0–1 (ไม่ต้องมีหน่วย)
>
> แต่ละ Property รับ **ชนิดข้อมูลต่างกัน** — ใส่ผิดชนิดจะได้ `Unable to cast`

## 6. ขั้นที่ 4 — ผสม `if` กับ Part

### 6.1 โจทย์: สีบอกสถานะ

ให้ Part เปลี่ยนสีตามคะแนน

| คะแนน      | สี     |
| :--------- | :----- |
| 80 ขึ้นไป  | เขียว  |
| 50–79      | เหลือง |
| ต่ำกว่า 50 | แดง    |

```lua
-- StatusColorScript
local part = workspace.PaintPart
local score = 85

if score >= 80 then
    part.Color = Color3.fromRGB(0, 200, 80)
elseif score >= 50 then
    part.Color = Color3.fromRGB(255, 220, 0)
else
    part.Color = Color3.fromRGB(220, 30, 30)
end

print("คะแนน " .. score .. " → เปลี่ยนสีแล้ว")
```

> [!tip] ลองแก้เลข
> เปลี่ยน `score` เป็น `65` แล้ว Play ใหม่ → ต้องได้สีเหลือง
> เปลี่ยนเป็น `30` → ต้องได้สีแดง

### 6.2 ประยุกต์ในเกมจริง

| สถานการณ์     | เงื่อนไข                                                     |
| :------------ | :----------------------------------------------------------- |
| ประตูเปิด/ปิด | `if hasKey then part.Transparency = 1`                       |
| แท่นไฟ        | `if isPressed then part.Material = Enum.Material.Neon`       |
| ธงเจ้าของฐาน  | `if team == "red" then part.Color = Color3.fromRGB(255,0,0)` |

> [!note] ทำไมต้องมี `if` ครอบ
> การเปลี่ยนสีเป็นคำสั่งธรรมดา — ถ้าไม่มี `if` สีจะถูกเปลี่ยนทุกครั้งที่รัน
> `if` ทำให้เปลี่ยน **เฉพาะเมื่อเงื่อนไขเป็นจริง** (คะแนนถึงเกณฑ์)
> และเพราะใช้ `if / elseif / else` จึงมั่นใจได้ว่าได้สีเดียวเท่านั้น

## 7. ขั้นที่ 5 — สร้าง Part ใหม่ด้วย `Instance.new`

### 7.1 สร้าง 1 ก้อน

```lua
-- SpawnBlockScript
local newPart = Instance.new("Part")
newPart.Size = Vector3.new(4, 1, 4)
newPart.Position = Vector3.new(0, 6, 0)
newPart.Anchored = true
newPart.Color = Color3.fromRGB(0, 200, 80)
newPart.Material = Enum.Material.Neon
newPart.Parent = workspace
```

**ผลลัพธ์:** มี Block สีเขียวลอยอยู่กลางฉาก

### 7.2 กฎที่ต้องจำ

| กฎ                                          | เหตุผล                                    |
| :------------------------------------------ | :---------------------------------------- |
| ตั้ง `Parent` เป็น **บรรทัดสุดท้าย**        | ถ้าตั้งก่อน ของจะโผล่แล้วกระพริบตอนแก้ค่า |
| ต้อง `Anchored = true` ก่อนหรือพร้อมกัน     | ไม่งั้นของจะร่วงลงพื้น                    |
| ตั้ง `Position` เป็น `Vector3.new(x, y, z)` | หน่วยเป็น studs                           |

> [!warning] ลืม `Parent`
> ถ้าลืม `newPart.Parent = workspace` ของจะไม่โผล่ในเกมเลย
> แต่ไม่ error — เป็นบั๊กเงียบที่หาสาเหตุยาก

> [!note] อ่านโค้ดสร้าง Part
> | บรรทัด | ทำอะไร | ถ้าลืม |
> | :--- | :--- | :--- |
> | `Instance.new("Part")` | สร้างของใหม่ (ยังไม่โผล่ในเกม) | — |
> | `Size` / `Position` | กำหนดรูปร่างและที่อยู่ | ของเล็ก/อยู่ที่ 0,0,0 |
> | `Anchored = true` | ล็อกไม่ให้ร่วง | ของตกลงพื้นทันที |
> | `Parent = workspace` | เอาเข้าฉาก (บรรทัดสุดท้าย) | ของไม่โผล่เลย |
>
> `Instance.new` สร้าง **1 ชิ้นต่อ 1 ครั้ง** — ถ้าอยากได้หลายชิ้นต้องใช้ลูป (`for`)

## 8. ขั้นที่ 6 — `for` loop สร้างของซ้ำ

### 8.1 รูปแบบ

```lua
for i = 1, 5 do
    -- ทำซ้ำ 5 ครั้ง โดย i = 1, 2, 3, 4, 5
end
```

### 8.2 สร้างบันได 5 ขั้น

```lua
-- StairScript
for i = 1, 5 do
    local step = Instance.new("Part")
    step.Size = Vector3.new(4, 0.5, 4)
    step.Position = Vector3.new(0, i * 2, i * 4)
    step.Anchored = true
    step.Color = Color3.fromRGB(0, 170, 255)
    step.Parent = workspace
end

print("สร้างบันได 5 ขั้นเสร็จแล้ว")
```

| ส่วน              | ความหมาย                  |
| :---------------- | :------------------------ |
| `for i = 1, 5 do` | วน 5 รอบ                  |
| `i * 2`           | ความสูงเพิ่มทีละ 2 studs  |
| `i * 4`           | ระยะห่างเพิ่มทีละ 4 studs |
| `end`             | ปิดลูป                    |

**ผลลัพธ์:** บันได 5 ขั้นเรียงขึ้นเป็นขั้นบันได

### 8.3 ผสม `if` ในลูป: สลับสีขั้นคู่–คี่

```lua
for i = 1, 6 do
    local step = Instance.new("Part")
    step.Size = Vector3.new(4, 0.5, 4)
    step.Position = Vector3.new(0, i * 2, i * 4)
    step.Anchored = true

    if i % 2 == 0 then
        step.Color = Color3.fromRGB(255, 220, 0)   -- ขั้นคู่ สีเหลือง
    else
        step.Color = Color3.fromRGB(0, 170, 255)   -- ขั้นคี่ สีฟ้า
    end

    step.Parent = workspace
end
```

> [!note] `i % 2 == 0` คืออะไร
> `%` หาเศษจากการหาร · เลขคู่หาร 2 ลงตัว เศษเป็น 0
> ใช้บ่อยมากในการสลับสี ทำลาย หรือแบ่งของเป็นชุด

> [!note] ทำไมต้อง i * 2 และ i * 4
> `i` เปลี่ยนค่า 1→5 ทุกรอบ จึงใช้คำนวณตำแหน่งให้ขยับเอง
>
> | รอบ | i x 2 (สูง) | i x 4 (ห่าง) |
> | :--: | :--: | :--: |
> | 1 | 2 | 4 |
> | 2 | 4 | 8 |
> | 5 | 10 | 20 |
>
> ถ้าใส่เลขคงที่ เช่น `Vector3.new(0, 2, 0)` ทุกขั้นจะซ้อนกันที่จุดเดียว
