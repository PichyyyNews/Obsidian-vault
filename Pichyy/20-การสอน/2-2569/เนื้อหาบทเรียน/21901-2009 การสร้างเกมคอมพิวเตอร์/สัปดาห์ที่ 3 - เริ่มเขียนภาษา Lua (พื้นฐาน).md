## 2. สคริปต์คืออะไร (ทฤษฎี 30 นาที)

### 2.1 ความหมายแบบภาษาคน

สคริปต์ = **ชุดคำสั่งที่เขียนไว้ล่วงหน้า** ให้เกมทำตามโดยอัตโนมัติ
เหมือนrecipes: ถ้าเราเขียนว่า "พิมพ์คำว่าสวัสดี" เกมก็จะพิมพ์ทุกครั้งที่เริ่มเล่น

### 2.2 สคริปต์ 3 ชนิดใน Roblox

| ชนิด             | ทำงานฝั่ง               | ใช้ทำอะไร                       | เรียนเมื่อไหร่ |
| :--------------- | :---------------------- | :------------------------------ | :------------- |
| **Script**       | Server                  | ลอจิกเกม ควบคุม Part คะแนน ด่าน | **สัปดาห์นี้** |
| **LocalScript**  | Client (เครื่องผู้เล่น) | UI, กล้อง, ปุ่มกด               | สัปดาห์ที่ 12  |
| **ModuleScript** | แล้วแต่ถูกเรียก         | เก็บฟังก์ชันใช้ซ้ำ              | สัปดาห์ที่ 6   |

> [!warning] ตัวที่ทำให้งานไม่เดิน
> ถ้าเลือก `LocalScript` แล้ววางใน `ServerScriptService` โค้ดจะ **ไม่ทำงานเลย**
> งานสัปดาห์นี้ใช้ **Script** เท่านั้น

### 2.3 วางสคริปต์ไว้ที่ไหน

| ตำแหน่งใน Explorer | เหมาะกับ | หมายเหตุ |
| :--- | :--- | :--- |
| `ServerScriptService` | สคริปต์หลักของเกม | **ใช้สัปดาห์นี้** |
| ในตัว `Part` | สคริปต์ของของชิ้นนั้น | สัปดาห์ที่ 7 (กับดัก) |
| `StarterPlayerScripts` | LocalScript | ยังไม่ใช้ |
| `StarterGui` | UI | สัปดาห์ที่ 11–12 |

### 2.4 กฎการเขียน Lua 5 ข้อ

| ข้อ | กฎ                        | ตัวอย่างถูก           | ตัวอย่างผิด    |
| :-: | :------------------------ | :-------------------- | :------------- |
|  1  | คำสั่งภาษาอังกฤษตัวเล็ก   | `print`               | `Print`        |
|  2  | ไม่ต้องใส่ `;` ท้ายบรรทัด | `print("hi")`         | `print("hi");` |
|  3  | ข้อความต้องมีคำพูดครอบ    | `"สวัสดี"`            | `สวัสดี`       |
|  4  | บล็อกต้องปิดด้วย `end`    | `if ... then ... end` | `if ... then`  |
|  5  | ย่อหน้าเพื่ออ่านง่าย      | 4 เคาะ                | เขียนชิด       |

> [!note] ภาษาไทยในโค้ด
> ใช้ได้ **เฉพาะในเครื่องหมายคำพูด** เช่น `print("สวัสดี")`
> ห้ามตั้งชื่อตัวแปรเป็นภาษาไทย (`ชื่อ = "นัท"` ใช้ไม่ได้)

## 3. ปฏิบัติที่ 1 — เปิด Output และพิมพ์คำสั่งแรก

### 3.1 เปิดหน้าต่างที่ต้องใช้

1. เปิด Roblox Studio และโปรเจกต์ของตัวเอง
2. ไปที่แท็บ **View**
3. ติ๊ก **Output** (หน้าต่างข้อความ)
4. ติ๊ก **Explorer** และ **Properties** ด้วย

> [!tip] หา Output ไม่เจอ
> กด **View → Output** ซ้ำอีกครั้ง หน้าต่างจะโผล่มาที่ด้านล่าง พร้อมปุ่ม **Clear** ไว้ลบข้อความเก่า

### 3.2 ลองพิมพ์ด้วย Command Bar

1. เปิด **View → Command Bar** (ช่องพิมพ์คำสั่งล่างจอ)
2. คลิกในช่อง แล้วพิมพ์

```lua
print("สวัสดี Roblox")
```

3. กด **Enter**
4. มองที่แท็บ **Output** → ควรเห็น `สวัสดี Roblox`

> [!note] อธิบายคำสั่งนี้
> | ส่วน | ความหมาย | ถ้าเขียนผิด |
> | :--- | :--- | :--- |
> | `print` | ชื่อคำสั่งที่ Roblox เตรียมไว้ให้ | พิมพ์ `Print` → `attempt to call a nil value` |
> | `( )` | วงเล็บใส่สิ่งที่อยากให้พิมพ์ | ลืม `)` → `Expected ')'` |
> | `"..."` | ข้อความ ต้องมีคำพูดเปิด–ปิด | ลืมคำพูด → `unexpected symbol` |
>
> อ่านเป็นภาษาคน: **"ปริ้นต์ ข้อความนี้"** — ชื่อคำสั่งมาก่อน ในวงเล็บคือสิ่งที่อยากให้ทำ

### 3.3 อ่าน Output ให้เป็น

| สิ่งที่เห็น     | ความหมาย                       | ควรทำ                   |
| :-------------- | :----------------------------- | :---------------------- |
| ข้อความธรรมดา   | ทำงานถูก                       | ผ่าน                    |
| ข้อความสีแดง    | Error — โค้ดพัง                | อ่านบรรทัดที่บอกแล้วแก้ |
| ข้อความสีเหลือง | Warning — ไม่พัง แต่ควรแก้     | แก้ถ้ามีเวลา            |
| ว่างเปล่า       | ยังไม่รัน หรือวางสคริปต์ผิดที่ | กด Play / ตรวจตำแหน่ง   |

## 4. ปฏิบัติที่ 2 — HelloScript (สคริปต์แรก)

### 4.1 สร้างสคริปต์

1. ใน **Explorer** หา **ServerScriptService**
2. คลิกขวา → **Insert Object** → เลือก **Script**
3. ตั้งชื่อ (ช่อง Name ใน Properties) ว่า `HelloScript`

> [!warning] ตรวจก่อนไปต่อ
> ใน Explorer ต้องขึ้นคำว่า `Script` ไม่ใช่ `LocalScript`
> ถ้าสร้างผิด ให้ลบแล้วสร้างใหม่ — อย่าเสียเวลาแก้

### 4.2 พิมพ์โค้ด

ลบโค้ดเดิม (`print("Hello world!")`) ให้หมด แล้วพิมพ์ตามนี้

```lua
-- HelloScript
-- ผู้เขียน: (ใส่ชื่อเล่นของตัวเอง)
print("สวัสดี Roblox!")
print("ฉันชื่อ ...")
print("วันนี้ฉันเริ่มเขียนภาษา Lua")
```

### 4.3 ทดสอบ

1. กด **Play (F5)**
2. ดูแท็บ **Output**
3. ควรเห็น 3 บรรทัด
4. กด **Stop (Shift + F5)**

**ผลลัพธ์ที่ควรเห็น**

```text
สวัสดี Roblox!
ฉันชื่อ นัท
วันนี้ฉันเริ่มเขียนภาษา Lua
```

### 4.4 อธิบายทีละบรรทัด

| โค้ด             | ความหมาย                         |
| :--------------- | :------------------------------- |
| `-- HelloScript` | คอมเมนต์ 1 บรรทัด โปรแกรมข้ามไป  |
| `print("...")`   | สั่งพิมพ์ข้อความออก Output       |
| `"..."`          | ข้อความ (string) ต้องมีคำพูดครอบ |

### 4.5 คอมเมนต์ 2 แบบ

```lua
-- แบบที่ 1: บรรทัดเดียว

--[[
    แบบที่ 2: หลายบรรทัด
    ใช้เขียนคำอธิบายยาว ๆ หรือปิดโค้ดชั่วคราว
]]
```

> [!danger] ทำไมแก้โค้ดแล้วไม่มีอะไรเปลี่ยน
> เพราะยังไม่ได้ **Stop แล้ว Play ใหม่**
> Studio ยังรันโค้ดเวอร์ชันเก่าอยู่ — จำลำดับนี้: **Stop → แก้ → Play**

## 5. ปฏิบัติที่ 3 — ตัวแปร (Variables)

### 5.1 ตัวแปรคือกล่องใส่ข้อมูล

```lua
local playerName = "นัท"
```

| ส่วน         | ความหมาย                   |
| :----------- | :------------------------- |
| `local`      | ประกาศตัวแปรใหม่ในบล็อกนี้ |
| `playerName` | ชื่อกล่อง (ตั้งเอง)        |
| `=`          | กำหนดค่า                   |
| `"นัท"`      | ค่าที่ใส่ลงไป              |

> [!tip] ทำไมต้องมี `local`
> ถ้าไม่ใส่ ตัวแปรจะเป็น global ทำให้เกมช้าและหาบั๊กยาก
> **กฎของเรา: สร้างตัวแปรทุกครั้งต้องมี `local`**

### 5.2 ชนิดข้อมูล 5 ชนิด

| ชนิด        | ตัวอย่าง            | ใช้ทำอะไร          | ต้องมีคำพูดไหม |
| :---------- | :------------------ | :----------------- | :------------: |
| **number**  | `10`, `3.14`, `-5`  | คะแนน ราคา จำนวน   |      ไม่       |
| **string**  | `"สวัสดี"`, `"Lua"` | ข้อความ ชื่อ       |     ต้องมี     |
| **boolean** | `true`, `false`     | สถานะ ผ่าน/ไม่ผ่าน |      ไม่       |
| **nil**     | `nil`               | ยังไม่มีค่า        |      ไม่       |
| **table**   | `{1, 2, 3}`         | เก็บหลายค่า        |      ไม่       |

### 5.3 ลองเขียน 5 ตัวแปร

สร้าง Script ใหม่ชื่อ `VariableScript` ใน `ServerScriptService`

```lua
-- VariableScript
local playerName = "นัท"
local age = 16
local score = 85
local isReady = true
local nothing = nil

print(playerName)
print(age)
print(score)
print(isReady)
print(nothing)
```

**ผลลัพธ์**

```text
นัท
16
85
true
nil
```

> [!note] สังเกต
> `print` พิมพ์ค่าเดี่ยว ๆ ได้ทุกชนิด รวมถึง `nil`
> แต่ถ้าจะ **ต่อกับข้อความ** ต้องระวัง (ดูหัวข้อ 6)

> [!note] อธิบายโค้ด 5 ตัวแปร
> | บรรทัด | ทำอะไร | ถ้าเขียนผิด |
> | :--- | :--- | :--- |
> | `local playerName = "นัท"` | สร้างกล่องเก็บข้อความ | ลืมคำพูด → หาตัวแปร `นัท` ไม่เจอ |
> | `local age = 16` | เก็บตัวเลข (ห้ามมีคำพูด) | ใส่ `"16"` → เป็นข้อความ คำนวณไม่ได้ |
> | `local score = 85` | เก็บคะแนนเป็นตัวเลข | ใส่ `85 คะแนน` → error |
> | `local isReady = true` | เก็บค่าจริง/เท็จ (ตัวเล็กทั้งหมด) | เขียน `True` → `Unknown global` |
> | `local nothing = nil` | กล่องเปล่า ยังไม่มีค่า | ใส่ `"nil"` → กลายเป็นข้อความ |
>
> สังเกต: **ข้อความ** ต้องมีคำพูด · **ตัวเลข / true / false / nil** ห้ามมีคำพูด

## 6. ปฏิบัติที่ 4 — ต่อข้อความด้วย `..`

### 6.1 ต่อข้อความเข้าด้วยกัน

```lua
local playerName = "นัท"
local age = 16

print("ชื่อ: " .. playerName)
print("อายุ: " .. age .. " ปี")
```

**ผลลัพธ์**

```text
ชื่อ: นัท
อายุ: 16 ปี
```

> [!tip] จำง่าย ๆ
> `..` (จุดสองจุด) = **กาวต่อข้อความ**
> ไม่ต้องเว้นวรรคเอง ถ้าอยากได้วรรคให้ใส่ `" "` ในเครื่องหมายคำพูด

> [!note] ทำไมต้องมี `..`
> ถ้าเขียน `print("ชื่อ: " playerName)` จะ error เพราะ Lua ไม่รู้จะเอาสองค่ามาต่อกันอย่างไร
> `..` คือคำสั่งบอกว่า **"เอาข้อความสองก้อนมาต่อกัน"**
> ถ้าใช้ `,` แทน จะได้ `ชื่อ:    นัท` โดยมีช่องว่างคั่น — คนละแบบกับ `..`

### 6.2 boolean ต่อตรง ๆ ไม่ได้

```lua
local isReady = true

-- ผิด: จะเกิด error
-- print("พร้อม: " .. isReady)

-- ถูก: แปลงก่อนด้วย tostring()
print("พร้อม: " .. tostring(isReady))
```

**ผลลัพธ์:** `พร้อม: true`

> [!warning] Error ที่เจอบ่อยที่สุด
> `attempt to concatenate boolean with string`
> เกิดจากเอา `true`/`false` ไปต่อกับข้อความ → ใช้ `tostring()` ครอบ

### 6.3 เปลี่ยนค่าตัวแปร

```lua
local score = 0
print("เริ่มต้น: " .. score)

score = score + 10
print("เก็บเหรียญที่ 1: " .. score)

score = score + 10
print("เก็บเหรียญที่ 2: " .. score)
```

**ผลลัพธ์**

```text
เริ่มต้น: 0
เก็บเหรียญที่ 1: 10
เก็บเหรียญที่ 2: 20
```

> [!note] ประกาศ `local` ครั้งเดียว
> ครั้งต่อไปที่แก้ค่า ใส่แค่ `score = ...` ไม่ต้องมี `local` ซ้ำ

> [!note] อ่านบรรทัด `score = score + 10` อย่างไร
> Lua คิด **ฝั่งขวาก่อน** แล้วค่อยเก็บผลไว้ฝั่งซ้าย
> 1. อ่านค่า `score` เดิม (เช่น 0)
> 2. บวก 10 → ได้ 10
> 3. เก็บ 10 กลับลงกล่อง `score`
>
> ถ้าเขียน `score + 10` เฉย ๆ (ไม่มี `=`) ค่าจะไม่เปลี่ยน — คำนวณแล้วทิ้งผลไป

## 7. ปฏิบัติที่ 5 — ตั้งชื่อตัวแปรให้เป็น

| กฎ                          | ถูก               | ผิด            | เพราะ                            |
| :-------------------------- | :---------------- | :------------- | :------------------------------- |
| ขึ้นต้นด้วยตัวอักษรหรือ `_` | `score`           | `1score`       | ขึ้นต้นด้วยเลข                   |
| ห้ามเว้นวรรค                | `playerScore`     | `player score` | มีช่องว่าง                       |
| ห้ามใช้คำสงวน               | `myScore`         | `end`          | เป็นคำสั่งของ Lua                |
| ตัวพิมพ์เล็ก–ใหญ่ต่างกัน    | `score` ≠ `Score` | —              | Lua แยกสองตัวนี้                 |
| ใช้ camelCase               | `totalScore`      | `total_score`  | อ่านง่ายกว่า (ไม่ผิด แต่ไม่นิยม) |

**คำสงวนที่ห้ามใช้ตั้งชื่อ**

```text
and  break  do  else  elseif  end  false  for  function  if  in
local  nil  not  or  repeat  return  then  true  until  while
```

> [!tip] ตั้งชื่อให้ "บอกหน้าที่"
> `score` ดีกว่า `a` · `playerName` ดีกว่า `n` · `isGameOver` ดีกว่า `x2`
> เพราะอีก 2 สัปดาห์เราจะกลับมาอ่านโค้ดนี้เอง

## 8. ปฏิบัติที่ 6 — โปรไฟล์ของฉัน (รวมทุกอย่าง)

สร้าง Script ชื่อ `ProfileScript` แล้วพิมพ์โค้ดนี้ (เปลี่ยนข้อมูลเป็นของตัวเอง)

```lua
-- ProfileScript
-- แสดงโปรไฟล์ผู้พัฒนาเกม

local playerName = "นัท"
local classRoom = "3ชทค2"
local age = 16
local favoriteGame = "Obby"
local isReady = true

print("=== โปรไฟล์ของฉัน ===")
print("ชื่อเล่น: " .. playerName)
print("กลุ่มเรียน: " .. classRoom)
print("อายุ: " .. age .. " ปี")
print("เกมที่ชอบ: " .. favoriteGame)
print("พร้อมสร้างเกม: " .. tostring(isReady))
print("====================")
```

**ผลลัพธ์**

```text
=== โปรไฟล์ของฉัน ===
ชื่อเล่น: นัท
กลุ่มเรียน: 3ชทค2
อายุ: 16 ปี
เกมที่ชอบ: Obby
พร้อมสร้างเกม: true
====================
```

> [!success] เช็กตัวเอง
> ถ้ารันผ่านครบทุกบรรทัด = เข้าใจ `print`, ตัวแปร, ชนิดข้อมูล และ `..` แล้ว

> [!note] เบื้องหลังโค้ดนี้
> * บรรทัด `print("=== ... ===")` ใช้ขีดคั่นเพื่อให้ Output อ่านง่าย (ไม่ใช่คำสั่งพิเศษ)
> * ทุกบรรทัดที่เริ่มด้วย `print` ให้ผล 1 บรรทัด — รวมแล้ว 7 บรรทัด
> * ถ้าลบคำพูดรอบชื่อออก (`playerName` ไม่มี `"`) จะได้ error เพราะไม่มีตัวแปรชื่อนั้น
> * `..` ต่อได้หลายก้อนในบรรทัดเดียว เช่น `"อายุ: " .. age .. " ปี"`

## 9. Error ที่พบบ่อยในสัปดาห์นี้

| ข้อความใน Output | สาเหตุ | วิธีแก้ |
| :--- | :--- | :--- |
| `Unknown global 'Print'` | พิมพ์คำสั่งตัวใหญ่ | เปลี่ยนเป็น `print` |
| `Expected ')' (to close '(' at line X)` | ลืมวงเล็บปิด | เติม `)` |
| `Expected identifier` | ลืมชื่อตัวแปร | `local = "x"` → `local name = "x"` |
| `attempt to concatenate boolean with string` | เอา boolean ต่อข้อความ | ใช้ `tostring()` |
| `unexpected symbol near '"'` | ใช้คำพูดผิดแบบ (เช่น `"สวัสดี'`) | เปิด–ปิดให้ตรงกัน |
| ไม่มีอะไรขึ้นใน Output | ยังไม่กด Play / วางผิดที่ | ตรวจตำแหน่ง + กด Play |

> [!tip] อ่าน error ให้เร็ว
> ดู **บรรทัดแรก** ของข้อความแดง จะบอกชื่อไฟล์และบรรทัด เช่น
> `ProfileScript:7: attempt to concatenate boolean with string` → ผิดบรรทัดที่ 7

## 12. คำถามทบทวนท้ายคาบ

1. สคริปต์จะทำงานเมื่อไหร่ และทำไมแก้โค้ดแล้วต้อง Play ใหม่
2. `Script` ต่างจาก `LocalScript` อย่างไร งานสัปดาห์นี้ใช้ชนิดใด
3. `local` มีไว้ทำอะไร ถ้าไม่ใส่จะเกิดอะไรขึ้น
4. ตัวแปร 5 ชนิดมีอะไรบ้าง ยกตัวอย่างชนิดละ 1 ค่า
5. ทำไม `"คะแนน: " .. true` จึง error และแก้อย่างไร
6. `..` ทำหน้าที่อะไร ต่างจาก `.` อย่างไร

> [!success]- เฉลย (คลิกเพื่อเปิด)
> 1. ทำงานตอนกด Play เพราะเป็นโหมดรันเกม ไม่ใช่โหมดแก้ไข
> 2. `Script` ฝั่ง Server ใช้กับลอจิกเกม · `LocalScript` ฝั่ง Client ใช้กับ UI — สัปดาห์นี้ใช้ `Script`
> 3. ประกาศตัวแปรในขอบเขตบล็อก ถ้าไม่ใส่จะเป็น global ทำให้ช้าและเกิดบั๊ก
> 4. number `10` · string `"ลูอา"` · boolean `true` · nil `nil` · table `{1, 2, 3}`
> 5. boolean ต่อกับ string ตรง ๆ ไม่ได้ ต้องใช้ `tostring(true)`
> 6. `..` ต่อข้อความ · `.` ใช้เข้าถึงสมาชิก เช่น `workspace.Part` (สัปดาห์ที่ 5)
