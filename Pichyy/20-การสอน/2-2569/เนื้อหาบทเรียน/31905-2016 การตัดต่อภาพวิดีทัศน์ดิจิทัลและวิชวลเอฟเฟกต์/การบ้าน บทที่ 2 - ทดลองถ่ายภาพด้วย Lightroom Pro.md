# การบ้าน บทที่ 2: ทดลองถ่ายภาพด้วย Lightroom Pro Camera

> [!abstract] โจทย์สั้น ๆ
> ออกไปถ่ายภาพด้วยมือถือโดยใช้ **Adobe Lightroom — โหมด Pro** ให้ครบ 4 ภารกิจ แต่ละภารกิจทดสอบค่าที่เรียนมาค่าหนึ่ง แล้วนำภาพมานำเสนอหน้าชั้นเรียนว่า ตั้งค่าอะไร ทำไม และภาพออกมาเป็นอย่างไร

---

## ก่อนเริ่ม — เตรียม Lightroom Pro Camera

### ติดตั้ง Lightroom บนมือถือ

1. เปิด **App Store** (iPhone) หรือ **Play Store** (Android)
2. ค้นหา **"Adobe Lightroom"** — ติดตั้งฟรี ไม่ต้องซื้อ
3. เปิดแอป → กดที่ **กล้อง (ไอคอนกล้อง)** มุมขวาล่าง
4. กดปุ่ม **"Pro"** ที่ด้านบน → จะเห็นแถบควบคุมด้านล่าง

### หน้าตา Pro Camera ที่ต้องรู้จัก

```
┌─────────────────────────────────────────┐
│              [viewfinder]               │
│                                         │
│  ◉ Histogram  (กราฟความสว่าง)           │
├─────────────────────────────────────────┤
│  SS      ISO      WB      EV      FOCUS │
│  1/60    100    5500K    ±0      AUTO   │
│  ↑ ชัตเตอร์ ISO  ไวท์บาแลนซ์ ชดเชย    │
└─────────────────────────────────────────┘
```

> [!note] ค่าที่จะใช้ใน Lightroom Pro
> - **SS** = Shutter Speed = ความเร็วชัตเตอร์ (เช่น 1/60, 1/500)
> - **ISO** = ISO = ความไวแสง (เช่น 100, 800, 3200)
> - **WB** = White Balance = ไวท์บาแลนซ์ (เป็นตัวเลข Kelvin เช่น 3200K, 5600K)
> - **EV** = Exposure Compensation = ชดเชยความสว่าง (+1, -1 ฯลฯ)

> [!warning] เรื่องรูรับอากาศบนมือถือ
> มือถือส่วนใหญ่ **ล็อกรูรับอากาศไว้ตายตัว** ปรับไม่ได้ เราจึงไม่มีการตั้งค่า f บน Lightroom Pro
> แต่เราสามารถ **จำลองผลของรูรับอากาศ** ได้โดยการปรับระยะห่างระหว่างกล้องกับวัตถุ — ยิ่งเข้าใกล้วัตถุ ฉากหลังจะยิ่งเบลอมากขึ้น (ภารกิจที่ 1)

---

## ภารกิจที่ 1 — ทดสอบ "ชัดตื้น vs ชัดลึก" (แทนรูรับอากาศ)

### เรียนรู้อะไร
เนื่องจากมือถือไม่มีการปรับรูรับอากาศได้ เราจะทดสอบให้เห็นว่า **ระยะห่างระหว่างกล้องกับวัตถุ** มีผลต่อความชัดลึก — ยิ่งเข้าใกล้วัตถุมากเท่าไหร่ ฉากหลังจะเบลอมากขึ้นเท่านั้น

### วิธีทำ

**ภาพที่ 1A — ชัดตื้น (หลังเบลอ)**
1. หาวัตถุสักชิ้น เช่น ดินสอ กระป๋อง ดอกไม้ หรืออะไรก็ได้
2. วางไว้บนโต๊ะ ฉากหลังให้มีสิ่งของหรือผนังอยู่ห่างออกไปอีก 1–2 เมตร
3. นำกล้อง **เข้าใกล้วัตถุมาก ๆ** ห่างแค่ 10–15 ซม.
4. โฟกัสที่วัตถุ → ถ่าย
5. สังเกตว่าฉากหลังเบลอไหม

**ภาพที่ 1B — ชัดลึก (ทั้งภาพชัด)**
1. วัตถุเดิม ฉากหลังเดิม
2. **ถอยกล้องออกไปไกล** ประมาณ 1 เมตร
3. โฟกัสที่วัตถุ → ถ่าย
4. สังเกตว่าฉากหลังชัดขึ้นไหม

### สิ่งที่ต้องส่ง
- ภาพ 1A และ 1B (วัตถุเดียวกัน ฉากเดียวกัน แต่ระยะห่างต่างกัน)
- บันทึก: ถ่ายภาพ A ห่างเท่าไหร่ ภาพ B ห่างเท่าไหร่
- อธิบายว่าทำไมระยะห่างจึงมีผลต่อความเบลอของฉากหลัง

---

## ภารกิจที่ 2 — ทดสอบ "ชัตเตอร์" (หยุดการเคลื่อนไหว vs เบลอ)

### เรียนรู้อะไร
ทดสอบให้เห็นชัดว่า **ชัตเตอร์เร็ว** หยุดการเคลื่อนไหวได้ และ **ชัตเตอร์ช้า** ทำให้การเคลื่อนไหวเบลอเป็นทาง

### วิธีทำ

> [!tip] หาวัตถุที่เคลื่อนไหว
> แนะนำ: น้ำจากก๊อกน้ำ / พัดลม / เพื่อนโยนลูกบอล / มือตัวเองกวัดแกว่ง

**ภาพที่ 2A — ชัตเตอร์เร็ว (หยุดนิ่ง)**
1. ใน Lightroom Pro กดที่ **SS** แล้วตั้งเป็น **1/500** หรือเร็วกว่า
2. ISO ตั้งเป็น **Auto** ไปก่อน (Lightroom จะปรับให้สว่างพอ)
3. ถ่ายวัตถุที่กำลังเคลื่อนไหว
4. ผลที่ควรได้: วัตถุหยุดนิ่งคมชัด

**ภาพที่ 2B — ชัตเตอร์ช้า (เบลอเป็นทาง)**
1. ใน Lightroom Pro ตั้ง **SS** เป็น **1/15** หรือ **1/8**
2. ISO ตั้งเป็น **100** (ต่ำที่สุดเพื่อไม่ให้สว่างเกิน)
3. **วางมือถือบนโต๊ะหรือขอบหน้าต่าง** เพื่อป้องกันภาพสั่น
4. ถ่ายวัตถุที่กำลังเคลื่อนไหวเดิม
5. ผลที่ควรได้: วัตถุเบลอเป็นทาง ฉากหลังคม

> [!note] ถ้าภาพ 2B สว่างเกิน
> แสงกลางวันอาจทำให้ภาพสว่างเกินที่ชัตเตอร์ 1/15 ให้ถ่ายในที่ร่มหรือในห้องแทน

### สิ่งที่ต้องส่ง
- ภาพ 2A และ 2B (วัตถุเดียวกันกำลังเคลื่อนไหว)
- บันทึก: ตั้ง SS เท่าไหร่ในแต่ละภาพ, ISO เท่าไหร่
- อธิบาย: ทำไมภาพหนึ่งหยุดนิ่งและอีกภาพเบลอ

---

## ภารกิจที่ 3 — ทดสอบ ISO (แสงน้อย-มาก vs นอยซ์)

### เรียนรู้อะไร
ทดสอบให้เห็นว่า **ISO สูงทำให้ภาพสว่างในที่มืด แต่มีนอยซ์** และ **ISO ต่ำภาพสะอาดแต่ต้องการแสงมาก**

### วิธีทำ

> [!tip] เลือกฉากที่มีแสงน้อย
> ห้องที่ปิดไฟส่วนหนึ่ง / มุมมืดในห้อง / ทางเดินที่แสงน้อย / ถ่ายตอนเย็นในร่ม

**ถ่ายวัตถุเดิม 3 ภาพ ISO ต่างกัน ชัตเตอร์เท่ากัน**

ตั้ง SS = **1/60** คงที่ตลอด แล้วถ่าย 3 ภาพ:

| ภาพ | ตั้ง ISO | ที่ต้องสังเกต |
| :--- | :--- | :--- |
| 3A | ISO **100** | ภาพมืดหรือสว่างแค่ไหน สะอาดไหม |
| 3B | ISO **800** | สว่างขึ้นไหม เริ่มมีเม็ดหรือยัง |
| 3C | ISO **3200** หรือสูงสุดที่มือถือทำได้ | สว่างขึ้นอีก แต่เม็ดนอยซ์ชัดขึ้นไหม |

> [!note] วิธีดูนอยซ์
> หลังถ่ายแล้วขยายภาพดูในบริเวณที่มืด ๆ ของภาพ — นอยซ์จะเห็นเป็นเม็ดหรือจุดสีผิดปกติ ชัดที่สุดในบริเวณเงามืด

### สิ่งที่ต้องส่ง
- ภาพ 3A, 3B, 3C (วัตถุและชัตเตอร์เดิม ISO ต่างกัน)
- บันทึก: ISO แต่ละภาพคือเท่าไหร่
- อธิบาย: เห็นนอยซ์ชัดในภาพไหนมากที่สุด และดูอย่างไรถึงรู้ว่านอยซ์

---

## ภารกิจที่ 4 — ทดสอบ White Balance (เปลี่ยนบรรยากาศด้วย Kelvin)

### เรียนรู้อะไร
ทดสอบให้เห็นว่า **ค่า Kelvin** ต่างกันทำให้ภาพออกสีต่างกัน และเราใช้มันสร้างบรรยากาศได้

### วิธีทำ

> [!tip] เลือกฉาก
> ถ่ายอะไรก็ได้ที่มีสีขาวให้เห็นในภาพ เช่น กระดาษขาว ผนังสีขาว หรือเสื้อขาว — จะทำให้เห็นความเปลี่ยนแปลงของสีชัดเจนที่สุด

**ถ่าย 3 ภาพ ตำแหน่งเดียวกัน WB ต่างกัน**

ใน Lightroom Pro กดที่ **WB** แล้วเลื่อนเป็น Manual (K) แล้วตั้งค่าตามนี้:

| ภาพ | ตั้ง WB | บรรยากาศที่ควรได้ |
| :--- | :--- | :--- |
| 4A | **3200 K** | ภาพออกส้ม-เหลือง อบอุ่น |
| 4B | **5600 K** | ภาพสีกลาง-ขาว ตามธรรมชาติ |
| 4C | **9000 K** | ภาพออกฟ้า เย็น |

> [!note] ถ้า Lightroom ไม่มีตัวเลข K ให้ตั้ง
> ให้ใช้ Preset ที่มีอยู่แทน: Tungsten (ส้ม) → Daylight (กลาง) → Cloudy/Shade (ฟ้า)

### สิ่งที่ต้องส่ง
- ภาพ 4A, 4B, 4C (ฉากเดียวกัน WB ต่างกัน)
- บันทึก: ตั้ง WB เท่าไหร่แต่ละภาพ
- อธิบาย: ถ้าต้องการถ่ายวิดีโอในห้องที่มีหลอดไส้ (ให้แสงสีส้ม) ควรตั้ง WB เท่าไหร่ และทำไม

---

## ภารกิจพิเศษ — ถ่ายภาพรวมที่ใช้ทุกสิ่งที่เรียนมา

### โจทย์
เลือกฉากที่ **ท้าทาย** สักฉาก แล้วถ่ายให้ออกมาดีที่สุดโดยตั้งค่าทุกอย่างเองด้วยมือ (ห้ามใช้ Auto ทุกค่า)

**ตัวอย่างฉากที่น่าสนใจ:**
- คนยืนด้านหน้าหน้าต่าง (แสงย้อน)
- ของบนโต๊ะในห้องที่แสงน้อย
- วัตถุที่กำลังเคลื่อนไหว เช่น พัดลม น้ำ

### สิ่งที่ต้องบันทึก

เมื่อได้ภาพที่พอใจแล้ว ให้จดไว้ในใบงาน:

| ค่าที่ตั้ง | ตัวเลขที่ใช้ | เหตุผลที่เลือก |
| :--- | :--- | :--- |
| SS (ชัตเตอร์) | | |
| ISO | | |
| WB (Kelvin) | | |
| EV (ชดเชย ±) | | |
| ปัญหาที่เจอ | | |
| วิธีแก้ที่ใช้ | | |

## รูปแบบการนำเสนอ

### ระยะเวลา
แต่ละคนนำเสนอ **5 นาที** หน้าชั้นเรียน

### สิ่งที่ต้องนำเสนอ

**1. แสดงภาพทั้งหมดบนมือถือหรือนำมาฉายบน TV/จอ**
ไม่ต้องทำ PowerPoint ก็ได้ — เอามือถือมาแสดงตรง ๆ ได้เลย

**2. เล่าให้ครบทุกภาพว่า:**
- ถ่ายอะไร ที่ไหน
- ตั้งค่าอะไรบ้าง (SS / ISO / WB)
- ทำไมถึงเลือกค่านั้น
- ภาพออกมาตรงที่ต้องการไหม — ถ้าไม่ตรง จะแก้อย่างไร

**3. เปิด Histogram ของภาพพิเศษให้ดู**
- Lightroom มี Histogram ในหน้าแก้ไขภาพ
- บอกได้ไหมว่า Histogram ของภาพนั้นบอกอะไร

## เกณฑ์การให้คะแนน (20 คะแนน)

| หัวข้อ | คะแนน | เกณฑ์ |
| :--- | :--: | :--- |
| **ภารกิจที่ 1** ชัดตื้น-ชัดลึก | 4 | ครบ 2 ภาพ + อธิบายได้ว่าทำไมต่างกัน |
| **ภารกิจที่ 2** ชัตเตอร์เร็ว-ช้า | 4 | ครบ 2 ภาพ + บอกค่า SS ที่ใช้ได้ |
| **ภารกิจที่ 3** ISO ต่าง ๆ | 4 | ครบ 3 ภาพ + ชี้นอยซ์ในภาพได้ |
| **ภารกิจที่ 4** White Balance | 4 | ครบ 3 ภาพ + อธิบาย Kelvin ได้ |
| **ภารกิจพิเศษ** + Histogram | 4 | มีภาพ + บันทึกค่า + อ่าน Histogram ได้ |

> [!tip] อยากได้คะแนนเต็ม ทำสิ่งนี้
> ไม่ใช่แค่ถ่ายภาพมา — ต้อง **อธิบายได้ว่า "ทำไม"** ถึงตั้งค่านั้น
> ถ้าภาพออกมาไม่ตรงที่ต้องการ แต่บอกได้ว่าจะแก้อย่างไร → ก็ได้คะแนนเต็มเช่นกัน

> [!caution] สิ่งที่ทำให้เสียคะแนน
> - ถ่ายด้วย **กล้องมือถือโหมดปกติ** แทน Lightroom Pro → ไม่มีหลักฐานว่าตั้งค่าเอง
> - ส่งภาพแต่ **ไม่จำได้** ว่าตั้งค่าอะไร
> - ไม่มีภาพ **เปรียบเทียบ** (ภาพเดียวไม่พอสำหรับภารกิจ 1–4)

---

## เคล็ดลับก่อนออกถ่าย

> [!note] ตั้งค่าตรงนี้ใน Lightroom ก่อนเริ่ม
> 1. Format ภาพ → ตั้งเป็น **JPG** (ไม่ต้อง DNG/RAW เพื่อให้ส่งง่าย)
> 2. เปิด **Histogram** ไว้ตลอด (แตะที่กราฟมุมบนขวา)
> 3. ล็อก **WB** ก่อนถ่ายทุกครั้ง อย่าปล่อย Auto

> [!tip] ถ่ายแล้วภาพสว่างเกิน/มืดเกิน
> ก่อนปรับ SS หรือ ISO ให้ลองปรับ **EV (ชดเชย)** ก่อน — เลื่อน +/- แล้วดู Histogram
> ถ้า Histogram ชนขอบขวา (ไฮไลต์ไหม้) → ลด EV ลงก่อน
