## 1. หัวข้อและจุดประสงค์การเรียนรู้ (Learning Content & Objectives)

### 1.1 หัวข้อการสอนประจำสัปดาห์ที่ 1
1. **ปฐมนิเทศรายวิชาและข้อตกลงในการเรียน:**
   - ชี้แจงจุดประสงค์ สมรรถนะ คำอธิบายรายวิชา และผลลัพธ์การเรียนรู้ระดับรายวิชา (CLO)
   - แผนการจัดการเรียนรู้ 18 สัปดาห์ (Roadmap) และโครงงานบูรณาการปลายภาค (Capstone Project)
   - กฎระเบียบความปลอดภัยในห้องปฏิบัติการ IOT การดูแลรักษาชุดทดลอง และเกณฑ์การประเมินผล 100 คะแนน
2. **ความรู้พื้นฐานระบบสมองกลฝังตัวและ IoT:**
   - นิยามและโครงสร้างของระบบสมองกลฝังตัว (Embedded System) เปรียบเทียบกับคอมพิวเตอร์ใช้งานทั่วไป (General Purpose PC)
   - แนวคิดและการเชื่อมต่อของ Internet of Things (IoT): สถาปัตยกรรม 3 ชั้น (Perception Layer -> Network Layer -> Application Layer)
   - ตัวอย่างการนำ IoT ไปใช้จริงในงานอุตสาหกรรม เกษตรอัจฉริยะ และบ้านอัจฉริยะ (Smart Home)
3. **แนะนำฮาร์ดแวร์บอร์ดไมโครคอนโทรลเลอร์ ESP32:**
   - ชิปประมวลผล Tensilica Xtensa Dual-Core 32-bit, สัญญาณนาฬิกา 240 MHz
   - คุณสมบัติการเชื่อมต่อไร้สายในตัว (Wi-Fi 802.11 b/g/n และ Bluetooth 4.2 BR/EDR & BLE)
   - แผนผังพิน (Pinout): พินดิจิทัล (GPIO), พินแอนะล็อก (ADC/DAC), แหล่งจ่ายไฟ (3.3V, 5V, GND) และพินข้อจำกัด (Input Only Pins)
4. **การเตรียมสภาพแวดล้อมการพัฒนา (Development Environment Setup):**
   - การติดตั้งไดรเวอร์สื่อสาร USB-to-UART (ชิป CP2102 หรือ CH340)
   - การติดตั้งซอฟต์แวร์ Arduino IDE 2.x
   - การติดตั้ง ESP32 Board Manager Package ผ่าน Additional Boards Manager URLs
   - โครงสร้างโปรแกรม Arduino C/C++: ฟังก์ชัน `setup()` และ `loop()`

### 1.2 จุดประสงค์เชิงพฤติกรรม (เมื่อจบบทเรียนนี้ผู้เรียนสามารถ)
- [ ] อธิบายความแตกต่างระหว่างระบบสมองกลฝังตัวกับระบบคอมพิวเตอร์ทั่วไปได้อย่างถูกต้อง
- [ ] ระบุองค์ประกอบพื้นฐานและคุณสมบัติเด่นของบอร์ด ESP32 ได้อย่างถูกต้อง
- [ ] ติดตั้งไดรเวอร์ USB, ซอฟต์แวร์ Arduino IDE และแพ็กเกจบอร์ด ESP32 บนเครื่องคอมพิวเตอร์ได้สำเร็จ
- [ ] อัปโหลดโค้ดทดสอบไฟกะพริบ (Blink) เข้าสู่บอร์ด ESP32 และสั่งให้ไฟ LED บนบอร์ดทำงานได้ถูกต้อง

### 2.2 ใบงานปฏิบัติการที่ 1: การติดตั้งสภาพแวดล้อมและทดสอบบอร์ด ESP32 (Lab 1)

> [!note] วัตถุประสงค์ใบงาน
> ฝึกทักษะการติดตั้งไดรเวอร์ การคอนฟิกบอร์ดบน Arduino IDE 2.x และการคอมไพล์/อัปโหลดโปรแกรมควบคุมไฟกะพริบลงบนบอร์ดทดลอง ESP32

#### ขั้นตอนการปฏิบัติงาน (Step-by-Step):
1. **การตรวจสอบฮาร์ดแวร์และพอร์ตสื่อสาร:**
   - เสียบสาย Micro-USB ระหว่างเครื่องคอมพิวเตอร์กับบอร์ด ESP32 NodeMCU-32S
   - เปิด `Device Manager` -> ตรวจสอบหัวข้อ `Ports (COM & LPT)` ว่าพอร์ตขึ้นชื่อ `Silicon Labs CP210x USB to UART Bridge` หรือ `USB-SERIAL CH340` และจดบันทึกหมายเลขพอร์ต (เช่น `COM3`, `COM5`)
   - *หากมีเครื่องหมายตกใจสีเหลือง ให้ติดตั้งไฟล์ไดรเวอร์ที่ครูเตรียมไว้ในไดรฟ์ส่วนกลางของห้อง*
2. **การตั้งค่าโปรแกรม Arduino IDE 2.x:**
   - เข้าเมนู `File -> Preferences`
   - ในช่อง **Additional boards manager URLs** วางลิงก์แพ็กเกจ:
     `https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`
   - เปิดแท็บ `Boards Manager` (ไอคอนบอร์ดด้านซ้าย) ค้นหาคำว่า `esp32` โดย Espressif Systems แล้วกด **Install**
3. **การเขียนโปรแกรมควบคุม GPIO2 (Onboard LED):**
   - พิมพ์โค้ดภาษา C/C++ ควบคุมไฟกะพริบดังนี้:

```cpp
// ใบงานที่ 1: การทดสอบบอร์ด ESP32 และการสั่งงาน GPIO2
// รหัสวิชา 31909-2003 การพัฒนางานระบบสมองกลฝังตัวและ IoT

const int LED_PIN = 2; // ขา Onboard LED ของ ESP32 NodeMCU-32S

void setup() {
  // เริ่มต้นการทำงานของพอร์ตอนุกรมความเร็ว 115200 bps
  Serial.begin(115200);
  Serial.println("ESP32 System Initializing...");
  
  // กำหนดให้ขาดิจิทัลหมายเลข 2 ทำหน้าที่เป็น Output
  pinMode(LED_PIN, OUTPUT);
  Serial.println("GPIO 2 configured as OUTPUT.");
}

void loop() {
  // สั่งให้ LED สว่าง (ลอจิก HIGH)
  digitalWrite(LED_PIN, HIGH);
  Serial.println("LED Status: ON");
  delay(1000); // หน่วงเวลา 1,000 มิลลิวินาที (1 วินาที)
  
  // สั่งให้ LED ดับ (ลอจิก LOW)
  digitalWrite(LED_PIN, LOW);
  Serial.println("LED Status: OFF");
  delay(1000); // หน่วงเวลา 1,000 มิลลิวินาที (1 วินาที)
}
```

4. **การเลือกบอร์ดและพอร์ตก่อนอัปโหลด:**
   - เมนู `Tools -> Board -> esp32 -> DOIT ESP32 DEVKIT V1`
   - เมนู `Tools -> Port -> เลือก COM Port ที่จดไว้`
   - เมนู `Tools -> Upload Speed -> 921600` (หรือ 115200 หากสายสัญญาณไม่เสถียร)
5. **การคอมไพล์และอัปโหลด:**
   - กดปุ่ม **Upload (ลูกศรขวา)**
   - รอจนขึ้นสถานะ `Connecting........_____.....`
   - *คำแนะนำพิเศษ:* หากขึ้นจุดค้าง ให้กดปุ่ม **BOOT (หรือ IO0)** บนตัวบอร์ด ESP32 ค้างไว้ 1-2 วินาที จนหน้าจอเริ่มเขียนเฟิร์มแวร์เป็นเปอร์เซ็นต์ (Writing at 0x00010000...)
6. **การตรวจสอบผลลัพธ์และการส่งงาน:**
   - สังเกตไฟ LED สีฟ้าบนตัวบอร์ดกะพริบสลับติด-ดับรอบละ 1 วินาที
   - เปิดหน้าต่าง **Serial Monitor** (แว่นขยายมุมขวาบน) ปรับ Baud rate ให้ตรงกับโค้ดคือ `115200 baud` ตรวจสอบข้อความแจ้งเตือนสถานะ LED

* **สไลด์ที่ 9 (Development Environment: Arduino IDE 2.x):**
  * แนะนำโปรแกรม Arduino IDE 2.x: UI ใหม่ มี Auto-complete และ Serial Plotter ในตัว
  * แนะนำชิปแปลง USB-to-UART (CP2102 vs CH340) และการตรวจเช็กใน Device Manager
* **สไลด์ที่ 10 (Setting Up ESP32 Board Package):**
  * ภาพหน้าจอขั้นตอนการวาง URL ใน Preferences
  * ภาพหน้าจอการติดตั้ง Espressif ESP32 package ผ่าน Boards Manager
* **สไลด์ที่ 11 (Arduino Code Anatomy):**
  * อธิบายโครงสร้าง 2 ฟังก์ชันหลัก:
    - `void setup()` : ทำงานเพียงครั้งเดียวเมื่อเปิดเครื่อง (กำหนดโหมดขา, เริ่มต้นพอร์ตสื่อสาร)
    - `void loop()` : วนซ้ำทำงานต่อเนื่องตลอดเวลาไม่มีวันหยุด
* **สไลด์ที่ 12 (Core Commands for GPIO):**
  * คำสั่ง `pinMode(pin, mode)` : กำหนดทิศทาง `INPUT` / `OUTPUT`
  * คำสั่ง `digitalWrite(pin, value)` : สั่งจ่ายแรงดันไฟ `HIGH` (3.3V) / `LOW` (0V)
  * คำสั่ง `delay(ms)` : หน่วงเวลาระบบเป็นมิลลิวินาที
  * คำสั่ง `Serial.begin(speed)` และ `Serial.println(msg)` : สื่อสารข้อความดีบักกลับสู่หน้าจอคอมพิวเตอร์
* **สไลด์ที่ 13 (Troubleshooting Common Errors):**
  * อาการที่ 1: คอมพิวเตอร์มองไม่เห็นพอร์ต COM -> ตรวจสอบสาย USB (ต้องเป็นสาย Data ไม่ใช่สายชาร์จเปล่า)
  * อาการที่ 2: ขึ้น `Failed to connect to ESP32: Timed out waiting for packet header` -> **กดปุ่ม BOOT ค้างไว้ตอนเริ่มอัปโหลด**
  * อาการที่ 3: หน้าจอ Serial Monitor แสดงตัวหนังสือเอเลี่ยนขยะภาษาต่างดาว -> ปรับ Baud rate ให้เป็น `115200`
* **สไลด์ที่ 14 (Lab 1 Mission & Summary):**
  * สรุปภารกิจใบงานที่ 1: ติดตั้งสำเร็จ + ไฟ Onboard LED กะพริบ + ส่งข้อความผ่าน Serial Monitor
  * สิ่งที่ต้องเตรียมมาในสัปดาห์ที่ 2: เบรดบอร์ด (Breadboard), สายไฟจัมเปอร์ (Jumper wires), สวิตช์ปุ่มกด และตัวต้านทาน

## 4. คลังชุดคำถามสำหรับผู้สอน (Question Bank พร้อมแนวคำตอบ)

### 4.1 คำถามนำเข้าสู่บทเรียนและกระตุ้นคิด (Pre-lesson / Ice Breaking)

> [!question] คำถามที่ 1
> **คำถาม:** "ในชีวิตประจำวันของเราตอนนี้ มีอุปกรณ์เครื่องใช้ไฟฟ้าหรือระบบใดบ้างที่ถือว่าเป็นระบบสมองกลฝังตัว (Embedded System) หรือเป็นอุปกรณ์ IoT?"
>
> **แนวคำตอบของผู้เรียน:** ไมโครเวฟ, ตู้เย็นอินเวอร์เตอร์, เครื่องซักผ้าอัตโนมัติ, สมาร์ตวอตช์, กล้องวงจรปิด Wi-Fi, ประตูคีย์การ์ดหอพัก, แอร์สั่งเปิดผ่านมือถือ
>
> **ประเด็นเฉลย/ขมวดเนื้อหาของผู้สอน:** จุดเด่นของระบบสมองกลฝังตัวคือมีชิปไมโครคอนโทรลเลอร์ฝังอยู่ภายในเพื่อทำหน้าที่เฉพาะอย่าง เช่น เครื่องซักผ้าวัดระดับน้ำและคุมมอเตอร์หมุน และเมื่ออุปกรณ์เหล่านั้นเชื่อมต่อเครือข่ายอินเทอร์เน็ตเพื่อส่งข้อมูลขึ้นคลาวด์หรือสั่งงานจากระยะไกลได้ มันจะยกระดับกลายเป็นอุปกรณ์ IoT

> [!question] คำถามที่ 2
> **คำถาม:** "ทำไมเราไม่นำคอมพิวเตอร์ PC หรือโน้ตบุ๊กไปติดตั้งควบคุมระบบรดน้ำต้นไม้ในสวน หรือคุมไฟตามทางเดิน แทนที่จะใช้บอร์ดไมโครคอนโทรลเลอร์ขนาดเล็ก?"
>
> **แนวคำตอบของผู้เรียน:** เปลืองเงิน, เปลืองไฟ, เครื่องใหญ่เกินไป, พังง่ายถ้าโดนความชื้นหรือฝุ่น, ไม่ต้องการระบบประมวลผลสูงขนาดนั้น
>
> **ประเด็นเฉลย/ขมวดเนื้อหาของผู้สอน:** ถูกต้องที่สุด เพราะงานช่างวิศวกรรมต้องคำนึงถึง **ต้นทุน (Cost-effectiveness)**, **การใช้พลังงาน (Low Power Consumption)** และ **ความเสถียร (Reliability)** บอร์ด ESP32 ราคาหลักร้อย กินไฟเพียงไม่กี่มิลลิแอมป์ และทำงานต่อเนื่องได้หลายปีโดยไม่ต้องรีสตาร์ต

### 4.2 คำถามระหว่างสอนเพื่อตรวจสอบความเข้าใจ (Check for Understanding)

> [!question] คำถามที่ 3
> **คำถาม:** "บอร์ด ESP32 ใช้แรงดันไฟฟ้าในระดับตรรกะ (Logic Level) ของขาดิจิทัลอยู่ที่กี่โวลต์? และแตกต่างจากบอร์ด Arduino Uno แบบดั้งเดิมอย่างไร?"
>
> **แนวคำตอบของผู้เรียน:** ESP32 ใช้แรงดัน **3.3 โวลต์ (3.3V)** ขณะที่ Arduino Uno ใช้แรงดัน **5 โวลต์ (5V)**
>
> **ประเด็นเน้นย้ำความปลอดภัย:** ช่างคอมพิวเตอร์ต้องระวังอย่างยิ่ง หากนำเซนเซอร์ที่จ่ายไฟ 5V ต่อเข้าขา GPIO ของ ESP32 โดยตรงโดยไม่มีวงจรแบ่งแรงดัน (Voltage Divider) หรือ Level Shifter อาจทำให้ชิป ESP32 ไหม้เสียหายถาวรได้ทันที

> [!question] คำถามที่ 4
> **คำถาม:** "ถ้าเรานำโค้ดคำสั่ง `digitalWrite(LED_PIN, HIGH);` ไปวางไว้ในฟังก์ชัน `void setup()` แทนที่จะวางใน `void loop()` หลอดไฟ LED จะมีลักษณะการทำงานอย่างไร?"
>
> **แนวคำตอบของผู้เรียน:** หลอดไฟ LED จะติดสว่างค้างตลอดเวลา และจะไม่กะพริบ
>
> **ประเด็นเฉลย/ขมวดเนื้อหาของผู้สอน:** เพราะคำสั่งใน `setup()` ทำงานเพียงครั้งเดียวตอนเริ่มบูตระบบ หากต้องการให้เกิดการกระทำซ้ำๆ เช่น ติด-ดับสลับกัน จะต้องนำคำสั่งไปประมวลผลวนลูปอย่างต่อเนื่องในฟังก์ชัน `loop()`

### 4.3 คำถามท้ายคาบ / สรุปบทเรียน (Exit Ticket / Wrap-up)

> [!question] คำถามที่ 5 (ข้อสอบวัดความรู้ท้ายคาบ)
> **คำถาม:** "ในระหว่างการอัปโหลดโค้ดลงบอร์ด ESP32 หากโปรแกรม Arduino IDE ค้างอยู่ที่ข้อความ `Connecting........_____.....` และเกิด Error ว่าไม่สามารถเชื่อมต่อได้ เกิดจากสาเหตุใด และช่างเทคนิคมีวิธีแก้ไขเบื้องต้นอย่างไร?"
>
> **แนวคำตอบที่ถูกต้อง:**
> 1. **สาเหตุ:** บอร์ด ESP32 บางรุ่นวงจร Auto-Reset ไม่ดึงขา IO0 ลงกราวด์โดยอัตโนมัติ ทำให้ชิปไม่เข้าสู่โหมด Download Bootloader
> 2. **วิธีแก้ไข:** ให้กดปุ่ม **BOOT (หรือ IO0)** บนตัวบอร์ดค้างไว้ทันทีที่เห็นคำว่า `Connecting...` จนกระทั่งเริ่มเขียนเฟิร์มแวร์แล้วจึงปล่อยมือ หรือตรวจเช็กการเลือกหมายเลขพอร์ต COM ให้ตรงกับตัวบอร์ดจริง
