## 1. จุดประสงค์ สมรรถนะ และคำอธิบายรายวิชา

### 1.1 จุดประสงค์รายวิชา
1. เข้าใจหลักการทำงานของระบบสมองกลฝังตัว การพัฒนาโปรแกรมควบคุม และระบบอินเทอร์เน็ตของสรรพสิ่ง (IoT)
2. มีทักษะในการออกแบบวงจร เชื่อมต่อฮาร์ดแวร์ พัฒนาโปรแกรมควบคุมแบบโมดูล และประยุกต์ใช้งานร่วมกับระบบเครือข่ายและคลาวด์
3. มีกิจนิสัยในการปฏิบัติงานอย่างเป็นระบบ มีความคิดสร้างสรรค์ คำนึงถึงความปลอดภัย จรรยาบรรณวิชาชีพ และรักษาสภาพแวดล้อม

### 1.2 สมรรถนะรายวิชา (Course Competencies)
1. ประมวลความรู้เกี่ยวกับเทคโนโลยีระบบสมองกลฝังตัวและ IoT ตามหลักการ
2. ออกแบบระบบสมองกลฝังตัวและ IoT ตามที่กำหนด
3. พัฒนาโปรแกรมประยุกต์ระบบสมองกลฝังตัวและ IoT ตามความต้องการของผู้ใช้
4. ประยุกต์ใช้ความรู้และทักษะในการพัฒนาโปรแกรมประยุกต์ระบบสมองกลฝังตัวและ IoT ตามหลักการ

### 1.3 ผลลัพธ์การเรียนรู้ระดับรายวิชา (CLO)
> "พัฒนาโปรแกรมประยุกต์ระบบสมองกลฝังตัวและ IoT ตามหลักการ ด้วยความละเอียด รอบคอบ รับผิดชอบและรักษาสภาพแวดล้อม"

### 1.4 คำอธิบายรายวิชา (Course Description)
> "ศึกษาและปฏิบัติเกี่ยวกับระบบสมองกลฝังตัวและ IoT เขียนโปรแกรมควบคุมแบบแยกส่วนเป็นโมดูลสำหรับระบบสมองกลฝังตัว ปฏิบัติการใช้เครื่องมือในการสร้างซอฟต์แวร์และติดตั้งลงบอร์ด ออกแบบสร้างวงจรควบคุมการทำงานของอุปกรณ์ไฟฟ้า อุปกรณ์อิเล็กทรอนิกส์หรือเครื่องจักรกลอัตโนมัติ ออกแบบรูปลักษณ์ของผลิตภัณฑ์และฟังก์ชันตามความต้องการ อ่านแบบวงจรอิเล็กทรอนิกส์ เลือกอุปกรณ์และ Footprint ให้สอดคล้องตามแบบ ทดสอบการทำงาน บันทึกข้อผิดพลาด และประยุกต์ใช้งานระบบสมองกลฝังตัวและ IoT"

## 2. ทิศทางเทคโนโลยีและการจัดการเรียนรู้ (Technology Stack)

1. **Hardware Architecture & GPIO**: ชิปไมโครคอนโทรลเลอร์ ESP32 NodeMCU-32S (Dual Core, 32-bit Tensilica Xtensa), Digital/Analog I/O (ADC 12-bit/DAC), PWM, Hardware Interrupts, Timer/millis() และการเชื่อมต่อบัส I2C/SPI
2. **Wireless & Connectivity Stack**: Wi-Fi (Station Mode, SoftAP Mode, Wi-Fi Multi), Web Server ฝังตัวควบคุมอุปกรณ์ และ Bluetooth Low Energy (BLE)
3. **IoT Protocols & Cloud Platforms**: โพรโทคอลสื่อสาร MQTT (Publish/Subscribe ผ่าน HiveMQ Cloud / EMQX), การสร้างแดชบอร์ดควบคุมระยะไกลด้วย Blynk IoT และระบบแจ้งเตือนฉุกเฉินอัตโนมัติผ่าน LINE Notify / Webhook API
4. **Modular C++ & Capstone Integration**: การเขียนโค้ดแบบแยกโมดูล Header/Source (`.h`/`.cpp`), การอ่านแบบวงจรและจัดทำ Footprint, โครงงานประยุกต์ Capstone Project รายกลุ่มวัดผลปลายภาค

| **4. การประเมินผลวัดความรู้ (Cognitive)** | 20% | การสอบวัดความรู้ทฤษฎีและข้อเขียนกลางภาค (10%) และปลายภาค (10%) |
