## 3. สื่อ อุปกรณ์ และสภาพแวดล้อมการเรียนรู้

1. **เครื่องคอมพิวเตอร์**: ห้องปฏิบัติการ TC203 เชื่อมต่อระบบอินเทอร์เน็ตความเร็วสูง
2. **Web Applications**: ChatGPT, Google Gemini Web Interface, Google AI Studio
3. **Developer Platforms**: OpenCode, VS Code, Node.js / Python Environment
4. **Cloud Free API**: Google AI Studio API (Gemini 2.0 Flash / 1.5 Flash), Groq Free Tier
5. **ชุดทดสอบ (Test Harness Framework)**: ชุดไฟล์คำถาม-คำตอบมาตรฐานสำหรับวัดผล Agent

## 4. การวัดและประเมินผล (น้ำหนัก 100%)

| องค์ประกอบ | น้ำหนัก | รายละเอียดเครื่องมือวัดผล |
| :--- | :---: | :--- |
| **1. ความรู้ภาคทฤษฎี** | 20% | แบบทดสอบก่อน-หลังเรียน, แบบทดสอบเรื่อง Context, Tokens และ Embeddings |
| **2. ทักษะปฏิบัติและใบงาน (Lab Work)** | 40% | การประเมินผลใบงาน 12 ใบงาน (Prompting, OpenCode, Skills, Harness) |
| **3. โครงงาน Specialized Agent (Capstone)** | 30% | ชิ้นงาน Agent ที่ทำงานได้จริง + ผลคะแนนจาก Test Harness + การนำเสนอ |
| **4. จิตพิสัยและคุณธรรม (Affection)** | 10% | การเข้าเรียน ตรงต่อเวลา จริยธรรมการใช้ AI และความรับผิดชอบ |

## 5. หมายเหตุสำหรับครูผู้สอน

> [!tip] การบริหารจัดการ API Key สำหรับผู้เรียน
> - ผู้เรียนทุกคนใช้บัญชี Google เพื่อรับ Free API Key จาก **Google AI Studio** ซึ่งไม่มีค่าใช้จ่ายและมีโควตารายวันเพียงพอสำหรับการเรียนการสอน
> - เน้นย้ำเรื่องความปลอดภัย: ห้ามนำ API Key ไปเผยแพร่ในสาธารณะ และสอนการเก็บคีย์ใน Environment Variables
> - โครงงานมุ่งเน้นให้นักเรียนเข้าใจตั้งแต่ระดับ "ผู้ใช้งาน" (Prompting) ไปจนถึง "ผู้ออกแบบระบบ" (Agent & Harness) ซึ่งสร้างความโดดเด่นให้แผนกช่างเทคนิคคอมพิวเตอร์อย่างมาก
