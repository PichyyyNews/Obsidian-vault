## 1. จุดประสงค์และสมรรถนะรายวิชา

### จุดประสงค์รายวิชา
เพื่อให้ผู้เรียน:
1. รู้และเข้าใจเกี่ยวกับหลักการออกแบบส่วนต่อประสานสำหรับงาน IoT ทั้งในรูปแบบคนคุยกับเครื่อง (H2M) และเครื่องคุยกับเครื่อง (M2M)
2. มีทักษะในการออกแบบและพัฒนาส่วนต่อประสานผู้ใช้ (UI/UX) หน้าจอ Dashboard บนโมบายแอปพลิเคชันและเว็บบราวเซอร์
3. มีทักษะในการประยุกต์ใช้โพรโทคอลการสื่อสารข้อมูล (REST API, MQTT, WebSocket) สำหรับเชื่อมต่ออุปกรณ์สมองกลฝังตัวเข้ากับส่วนต่อประสาน
4. มีเจตคติและกิจนิสัยที่ดีในการปฏิบัติงานด้วยความประณีต ปลอดภัย รับผิดชอบ และตรงต่อเวลา

### สมรรถนะรายวิชา
1. แสดงความรู้เกี่ยวกับหลักการ โครงสร้าง และโพรโทคอลส่วนต่อประสานสำหรับงาน IoT
2. ออกแบบและพัฒนาส่วนต่อประสานกราฟิก (GUI) สำหรับติดตามและควบคุมอุปกรณ์ IoT ตามข้อกำหนด
3. กำหนดค่าและเชื่อมโยงข้อมูลระหว่างไมโครคอนโทรลเลอร์กับแพลตฟอร์มส่วนต่อประสาน (Blynk / Node-RED / Web Dashboard)
4. ทดสอบและแก้ไขข้อผิดพลาดในการรับส่งข้อมูลผ่านส่วนต่อประสานของระบบ IoT
