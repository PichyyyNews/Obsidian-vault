## 3. จุดประสงค์รายวิชา

เพื่อให้ผู้เรียน

1. รู้และเข้าใจเกี่ยวกับแนวคิดพื้นฐานของการสร้างระบบปัญญาประดิษฐ์
2. มีทักษะในการเลือกและทดสอบใช้แอปพลิเคชันปัญญาประดิษฐ์ได้เหมาะสมกับงาน
3. มีเจตคติและกิจนิสัยที่ดีในการเรียนรู้ ทำงานด้วยความอดทน ผลงานประณีต ละเอียด รอบคอบ เป็นระเบียบ สะอาด ตรงต่อเวลา มีความซื่อสัตย์ รับผิดชอบ และรักษาสภาพแวดล้อม
4. มีความสามารถประยุกต์ใช้แอปพลิเคชันปัญญาประดิษฐ์ในงานอาชีพ

## 4. สมรรถนะรายวิชา

1. แสดงความรู้เกี่ยวกับแนวคิดพื้นฐานของการสร้างระบบปัญญาประดิษฐ์ตามหลักการ
2. เลือกและใช้แอปพลิเคชันปัญญาประดิษฐ์ตามลักษณะงาน
3. ทดสอบการทำงานแอปพลิเคชันปัญญาประดิษฐ์ได้ตามหลักการ
4. ประยุกต์ใช้แอปพลิเคชันปัญญาประดิษฐ์พัฒนางานอาชีพตามหลักการ

## 5. คำอธิบายรายวิชา

> ศึกษาและปฏิบัติเกี่ยวกับแนวคิดพื้นฐานของการสร้างระบบปัญญาประดิษฐ์ ใช้ในการตรวจจับ ติดตาม วัตถุหรือบุคคล ใช้ปัญญาประดิษฐ์ในการสร้างภาพแบบต่างๆ เช่น ภาพวาด ภาพการ์ตูน ฯลฯ การสร้างภาพเคลื่อนไหว การเขียนบทความ การสร้างเนื้อหา การออกแบบสินค้า ใช้ปัญญาประดิษฐ์ในการทำนายและเข้าใจภาษาธรรมชาติในรูปแบบของข้อความและคำพูด ใช้ปัญญาประดิษฐ์ในระบบนำทางรถยนต์ การจัดการการจราจร ระบบควบคุมหุ่นยนต์และทดสอบการทำงานแอปพลิเคชันปัญญาประดิษฐ์

## 6. แนวทางการจัดเนื้อหาและเทคโนโลยีที่ใช้ (Modern AI & LLM Focus)

ตามจุดเน้นของผู้สอนเพื่อให้นักเรียน ปวช.3 ได้เรียนรู้เทคโนโลยี AI ร่วมสมัยที่ใช้งานจริงในอุตสาหกรรม:

1. **LLM & Model Selection**: การใช้งานและเปรียบเทียบโมเดลภาษาขนาดใหญ่ (ChatGPT, Gemini, Claude, Open-weight models)
2. **Context Theory & Management**: Tokenization, System Instructions, Context Window, ข้อจำกัดและการบริหาร Context
3. **Embedding Models & Vector Search**: การฝังข้อความเป็นเวกเตอร์, ความคล้ายคลึงเชิงความหมาย (Semantic Similarity) และแนวคิด RAG (Retrieval-Augmented Generation) เบื้องต้น
4. **Prompt Engineering to Agents**: เทคนิคการเขียน Prompt (Zero-shot, Few-shot, CoT), การทำงานแบบ Agentic Workflow
5. **Context Skills & Tool Calling**: การเชื่อมต่อโมเดลกับเครื่องมือภายนอก (Function Calling / Tools / Skills)
6. **OpenCode & Cloud Free Models**: การใช้เครื่องมือฝั่ง Developer และโมเดล Cloud ฟรี (Google AI Studio Gemini API, Groq)
7. **Agent Harness & Evaluation**: การสร้างชุดทดสอบและวัดผลความแม่นยำของ AI Agent ตามสมรรถนะข้อ 3 "ทดสอบการทำงานแอปพลิเคชันปัญญาประดิษฐ์"

## 7. ชิ้นงานหลัก (Capstone Project)

> **โครงงานสร้าง Specialized Agent รายกลุ่ม**:
> พัฒนา AI Agent เฉพาะทางสำหรับงานช่างเทคนิคคอมพิวเตอร์ (เช่น Agent ช่วยตรวจแก้โค้ด, ช่างเทคนิคเสมือนช่วยวิเคราะห์ปัญหาฮาร์ดแวร์, หรือ Agent สรุปคู่มือเทคนิค) พร้อมจัดทำชุดทดสอบแบบ Test Harness เพื่อประเมินผลการทำงานจริง
